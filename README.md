# 页间 · Folio

一个本地 HTML 阅读工作空间。像 IDE 一样打开文件夹，像 PDF 阅读器一样做高亮、批注、手绘和笔记，同时编辑 HTML 源码。

## 下载与安装

[**下载最新版本**](https://github.com/XiangXiaoYuan5254/folio-html-reader/releases/latest) · [提交问题](https://github.com/XiangXiaoYuan5254/folio-html-reader/issues)

支持 **macOS 12 及以上**，无需 Node.js、终端或单独启动服务器。

| 你的 Mac | 下载文件 |
| --- | --- |
| Apple 芯片（M 系列） | `Folio-版本号-mac-arm64.dmg` |
| Intel 处理器 | `Folio-版本号-mac-x64.dmg` |

1. 打开下载的 DMG，把 **页间** 拖到 **Applications / 应用程序**。
2. 复制完成后推出磁盘映像，在“应用程序”或 Spotlight 中打开页间。
3. 点击左侧 **打开文件夹**，选择自己的 HTML 目录。首次启动提供三篇可自由编辑的原创演示文档。

### 首次打开提示

当前版本采用本地签名，**尚未取得 Apple Developer ID 签名和 Apple 公证**。如果 macOS 提示无法验证开发者，请先尝试打开一次，再到 **系统设置 → 隐私与安全性 → 仍要打开**。只对已确认来自本仓库发布页的应用执行此操作。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

若提示文件损坏或包含恶意内容，请停止安装，重新下载并核对发布页提供的 `SHA256SUMS.txt`。发布包不包含关闭系统安全保护的脚本。

### 更新与备份

先退出旧版，再将新版拖入“应用程序”并选择替换。阅读项目与批注数据独立于应用；更新前可备份整个阅读文件夹，记得包含隐藏的 `.html-reader`。

也提供 ZIP 压缩包：解压后将 `页间.app` 拖入“应用程序”。Mac 的芯片型号可在苹果菜单的“关于本机”中查看。

## 阅读与批注

- 左侧项目树与正文之间的分隔线可以左右拖动调整宽度，悬停显示调整光标；双击恢复默认宽度。调整后自动记住宽度，切换文件和重启仍保留；窗口变窄时临时限制目录宽度，恢复窗口后沿用你的设置。
- 左侧项目树可递归浏览文件夹、搜索文件、新建 HTML 和文件夹。悬停在文件行右侧的 `…` 可重命名、移动、移到废纸篓或在 Finder 中显示。
- 选中文字后，使用浮动工具条添加高亮或下划线。也可以先选工具，再拖选文字。
- **文本注释（T）** 是直接写在页面上的文字，背景透明，和便签分开。点击页面即可输入，悬停或编辑时显示移动标题、字号和删除控件；右下角调整文字宽度，点击勾号完成编辑。文字会随输入自动保存。
- 点击 **便签** 工具后，在页面任意位置单击，直接输入想法。拖动便签标题可以移动，拖动右下角可以调整大小；新便签自动沿用上次手动调整的尺寸，切换文档和重启应用后也会记住，已有便签保留各自大小。`−` 收起成小标记，垃圾桶删除，删除可以撤销。
- **高亮笔记** 附着在高亮的文字上；下划线也支持添加笔记。高亮、下划线完成后不会弹出面板；点击已有标记，再点 **添加笔记**，直接输入并点击 **完成**。有笔记的原文左上角会显示小三点，悬停原文或三点即可预览，此时三点暂时隐藏，移开后恢复；清空笔记后三点消失。点击原文可继续编辑、换色或删除，不需要打开右侧栏。旧版「原文笔记」自动作为高亮笔记使用，保留内容、颜色和原文位置。
- 选择画笔、箭头或矩形后，在页面拖动绘制。画笔显示随颜色变化的十字准星、圆环和中心点，中心点对应落笔位置，新笔迹进行平滑处理。橡皮擦显示圆形擦头，按住拖动可擦掉经过的局部笔迹，剩余部分保留；一次拖动可通过一次撤销恢复。高亮、文本注释和便签通过各自的删除按钮删除。
- **激光笔** 用红色发光轨迹临时指示，松开后约 3 秒淡出消失；不会进入批注列表、保存文件或撤销历史。按 `Esc` 可立即清除激光轨迹。
- 画笔和橡皮擦旁的设置按钮可调整笔触粗细、擦头大小。调节滑块时面板保持打开，点击面板外或在正文落笔时自动收起，第一笔直接生效。画笔模式下按住 `E` 临时擦除，松开恢复画笔。`⌘Z` 撤销，`⇧⌘Z` 重做；在便签输入框内，这两个快捷键处理文字编辑。
- 黄色、红色、绿色、蓝色和墨色适用于高亮、手绘、文本注释和便签。按 `Esc` 返回文字选择工具。鼠标悬停工具会显示中文名称和使用提示。
- 右侧 **批注** 可编辑每条标记的想法、搜索批注、点击回到原文。**笔记** 用于整篇文档的独立笔记，支持直接写 Markdown 文本；**目录** 根据 h1/h2/h3 生成跳转导航。
- 缩放默认适合宽度：HTML 铺满整个阅读区，按原网页的响应式样式排版，网页两侧留白也可以画线、贴便签。百分比缩放像浏览器一样调整大小并重新排版，两侧面板可收起，留出阅读空间。便签在收窄窗口后仍可访问，恢复宽度后回到原位置。
- 批注、笔记和阅读位置自动保存。右下角显示阅读进度。
- 批注不会自动打开右侧栏；侧栏仅由你手动开关，关闭状态在重启后仍然保留。可以收起侧栏，全屏专注阅读和页面批注。
- 右侧导出按钮可导出 Markdown 笔记及批注摘录。手绘在 Markdown 中以标记说明呈现，图形原始数据随项目保存。

## 编辑 HTML

点击 **源码**，左侧是带语法高亮、查找和撤销的源码编辑器，右侧是实时预览。编辑后预览自动更新；`⌘S` 或保存按钮写回原 HTML。

每次写回前都会保留上一个版本。如果文件被外部程序改动，应用会阻止覆盖，保留编辑器中的草稿并提示你合并。可以先复制草稿，再用源码工具栏的重新载入按钮载入磁盘版本。

关闭文件、切换文件夹或退出应用时，未保存的源码修改会提示确认。高亮按文字与前后文重新定位：原文被删掉时，笔记仍保留并显示“原文已变化”。点击 **重新关联**，选择新的原文，再点击浮动工具条的 **关联此批注** 即可修复。

当前提供源码编辑与实时预览；尚未实现任意 HTML 的所见即所得排版编辑。

## 数据在哪里

全部阅读数据保存在所打开的项目目录里：

```text
你的项目/
  文章.html
  图片与样式等资源/
  .html-reader/
    workspace.json          # 文档身份、路径和打开的标签页
    documents/<文档ID>.json  # 批注、画笔轨迹、笔记、位置、缩放
    backups/<文档ID>/*.html  # 保存源码前的历史版本
```

批注不会直接插入原 HTML。备份或搬走整个项目文件夹时，请一起保留隐藏的 `.html-reader` 目录。应用内重命名或移动文件会保留文档 ID；外部重命名可在原路径已消失且文件内容未变时恢复关联。

删除通过系统废纸篓完成，关联的批注仍保留。恢复原文件后可以继续读取笔记。移动 HTML 时，相对图片、CSS、脚本链接仍按新目录解释；应用不会自动重写这些源文件链接。

应用的最近工作空间设置保存在 macOS 的应用数据目录中。应用本身不上传文档；HTML 里原本引用的远程字体、脚本、图片仍会从对应网站加载。随包演示文档完全离线可用；用户自己的 HTML 若依赖 MathJax 等远程脚本，仍需网络。

## 开发与验证

需要 Node.js 22.12+，推荐使用 Node.js 22。项目包含 `.nvmrc`。

```sh
npm ci
npm run dev        # Vite + Electron 桌面开发
npm run build      # 类型检查、前端与阅读脚本构建
npm start          # 运行已经构建的桌面应用
npm test           # 文件保存、备份、冲突、路径边界等测试
npm run test:e2e   # 真实 Electron 中的交互回归测试
npm run test:annotations # 单独验证便签、局部擦除、中文提示和侧栏状态
npm run pack       # 构建当前架构的 .app
npm run dist:mac   # 构建 arm64 / x64 的 DMG、ZIP 和校验文件
```

`npm run dev:web` 提供只用于开发检查的网页入口。系统文件夹选择、Finder、废纸篓等功能需要桌面版本。不要同时用多个开发实例编辑同一个工作空间。

自动测试使用仓库中的 `samples/` 原创演示文档和测试代码生成的临时文件，不依赖个人资料或外部账号。覆盖本地资源、沙箱隔离、高亮、页面便签、手绘、局部擦除、撤销、笔记、目录、源码保存与备份、重定位、改名、移动、冲突和重启恢复。截图保存在系统临时目录。

开发时可以用 `FOLIO_WORKSPACE=/你的/HTML目录 npm run dev` 指定本地文件夹。额外的本地兼容性测试可设置 `FOLIO_TEST_SAMPLES`，默认不需要。个人阅读材料、批注、备份和本地配置均不进入版本控制或安装包。

## 实现结构

- `electron/workspace.cjs`：文件夹边界检查、文档身份、串行原子写入、备份和冲突检测。
- `electron/main.cjs`：窗口、原生菜单、文件选择、IPC 和文档资源协议。
- `src/reader/runtime.ts`：文档内的文字定位、SVG 手绘层与阅读事件。
- `src/hooks/useDocuments.ts`：标签页、草稿、批注历史和持久化队列。
- `src/components/`：文件树、工具栏、阅读区、源码编辑器、批注笔记栏。

文档在独立沙箱 iframe 中运行，无法直接访问文件系统接口。文件操作只允许在当前项目范围内进行。源码编辑器按需加载，阅读界面无需先加载编辑器。

本版本优先支持本地 UTF-8 静态 HTML、常见网页脚本、相对资源与公式。复杂网页应用、登录网站、嵌套网页、canvas 内部的文字批注、跨设备同步和 PDF 式分页导出不在当前版本范围内。页面大幅改版后，跨多个段落的自由手绘可能需要重新绘制。
