# 页间 · Folio

一个本地 HTML / PDF 阅读工作空间。像 IDE 一样打开文件夹，像 PDF 阅读器一样做高亮、批注、手绘和笔记，同时编辑 HTML 源码。

## 下载与安装

[**下载最新版本**](https://github.com/XiangXiaoYuan5254/folio-html-reader/releases/latest) · [提交问题](https://github.com/XiangXiaoYuan5254/folio-html-reader/issues)

支持 **macOS 12 及以上（Apple 芯片）** 和 **Windows 10 / 11（64 位）**，无需 Node.js、终端或单独启动服务器。

| 你的电脑                  | 下载文件                         |
| ------------------------- | -------------------------------- |
| Mac（Apple 芯片，M 系列） | `Folio-版本号-mac-arm64.dmg`     |
| Windows 10 / 11（64 位）  | `Folio-版本号-win-x64-setup.exe` |

### macOS

1. 打开下载的 DMG，把 **页间** 拖到 **Applications / 应用程序**。
2. 复制完成后推出磁盘映像，在“应用程序”或 Spotlight 中打开页间。
3. 点击左上角的 **选择项目**（`⌘O`），选择存放 HTML 或 PDF 的文件夹。首次启动会打开「示例文档」：五篇可自由编辑的原创演示文档，介绍各项功能，并附有批注、AI 和白板讲解的练习。

页间使用 Apple Developer ID 签名，并已通过 Apple 公证，下载后可以直接打开。第一次打开时 macOS 会确认一次“这是从互联网下载的 App，是否打开”，点 **打开** 即可。

Mac 的芯片型号可在苹果菜单的“关于本机”中查看。Intel 芯片的 Mac 暂不支持。

### Windows

1. 运行下载的 `Folio-版本号-win-x64-setup.exe`，按向导完成安装。默认只为当前用户安装，不需要管理员权限，也可以改安装位置。
2. 从开始菜单或桌面快捷方式打开 **页间**。
3. 点击左上角的 **选择项目**（`Ctrl+O`），选择存放 HTML 或 PDF 的文件夹。

安装后，在资源管理器中右键 HTML 文件，选择 **打开方式 → 页间** 即可直接阅读；安装程序不会更改你的默认浏览器。

安装程序**尚未进行代码签名**。运行时如果 Windows SmartScreen 提示“Windows 已保护你的电脑”，点击 **更多信息 → 仍要运行**。只对已确认来自本仓库发布页的安装包执行此操作。

### 校验与安全

若提示文件损坏或包含恶意内容，请停止安装，重新下载并核对发布页提供的 `SHA256SUMS.txt`。发布包不包含关闭系统安全保护的脚本。

### 更新与备份

页间会在后台下载新版本，下载好后提示重启；选“稍后”的话，下次退出时自动安装；页间一直开着的话，一天后会再提醒一次。点标题栏的“页间”可以手动检查更新。macOS 上，页间要放在“应用程序”文件夹里才能自动更新。

阅读项目与批注数据独立于应用；更新前可备份整个阅读文件夹，记得包含隐藏的 `.html-reader`。

## 设置

文档标签并入顶部标题栏。macOS 的“页间 Folio”标志在右上角；Windows 放在左上角，右上角留给系统最小化、最大化和关闭按钮。阅读工具栏的 **AI 助手与笔记** 统一开关右侧面板，面板内切换 **批注、笔记、目录、助手**。会员、主题、阅读提示和设置集中在左下角同一行。阅读工具栏空间足够时完整显示，放不下的批注工具收进 **更多工具**，拉宽后自动恢复。

点击左侧工作空间底部新增的 **齿轮**，或菜单中的 **设置…**，打开统一设置。左侧分为 **外观与阅读、AI、语音、会员、公告、关于**：可切换主题、调整划词工具条位置和高亮笔记字号、控制源码自动保存，管理 AI 服务与默认模型、读者画像、语音和会员。**公告**单独查看 AI 服务活动，**关于**查看版本、更新与常用快捷键。

讲解方式默认选择 **页老师出声**，之前保存的静音或语音对话选择继续保留。有新公告时，左下角齿轮、设置里的 **公告** 与原 AI 设置里的公告入口都会显示红点；从任一公告入口阅读后同步消除，重启后仍记得已读状态。打开其他设置页不会把公告标为已读。左下角 **?** 继续提供当前工具提示、阅读进度、批注数量和阅读快捷键。

原有入口和页面保持原样：助手和白板里的 AI 设置、菜单中的 **AI 设置…**，以及 `⌘,`（Windows 为 `Ctrl+,`），仍打开原来的独立 AI 设置窗口。左下角的主题按钮、会员按钮、点击标题栏“页间”检查更新，以及菜单中的 **界面主题…**、**会员与激活…** 也照常使用。新增统一设置与原有页面共用同一份配置；切换统一设置分类会保留正在填写的 AI 服务草稿，主题与阅读偏好即时生效并在重启后保留。

## 阅读与批注

- 工具栏右侧的 **专注阅读** 或 `⌘⇧F`（Windows 为 `Ctrl+Shift+F`）进入全屏阅读，隐藏标签页、工作空间和批注栏。鼠标移到顶部或点击右上角 **工具** 可呼出批注工具，回到正文落笔后自动收起；`Esc`、`⌘⇧F` 或 **退出专注** 返回原布局，双栏与批注保留。
- 保存状态位于左侧工作空间底部；点击旁边的 **?** 查看当前工具提示、快捷键、批注数量和阅读进度。阅读区不再占用整行底部状态栏。
- 左侧项目树与正文之间的分隔线可以左右拖动调整宽度，悬停显示调整光标；双击恢复默认宽度。调整后自动记住宽度，切换文件和重启仍保留；窗口变窄时临时限制目录宽度，恢复窗口后沿用你的设置。
- 左侧项目树可递归浏览文件夹、搜索文件、新建 HTML 和文件夹。文件夹使用暖黄色图标，HTML 文件使用蓝色图标，展开与折叠也有不同的文件夹图标。支持拖拽文件和文件夹到目标文件夹，悬停约半秒自动展开；拖到项目名称或列表空白处可移回根目录。文件仍按名称排序，拖拽改变实际所在文件夹。移动会保留批注、阅读标签和未保存的源码草稿；同名目标不会被覆盖。悬停在文件行右侧的 `…` 可重命名、移动、移到废纸篓或在 Finder 中显示（Windows 上为回收站和资源管理器）。
- 选中文字后，使用浮动工具条添加高亮或下划线。也可以先选工具，再拖选文字。
- **文本注释（T）** 是直接写在页面上的文字，背景透明，和便签分开。点击页面即可输入，悬停或编辑时显示移动标题、字号和删除控件；右下角调整文字宽度，点击勾号完成编辑。文字会随输入自动保存。
- 点击 **便签** 工具后，在页面任意位置单击，直接输入想法。拖动便签标题可以移动，拖动右下角可以调整大小；新便签自动沿用上次手动调整的尺寸，切换文档和重启应用后也会记住，已有便签保留各自大小。便签右上角的 **样式** 按钮可调整字号、切换系统字体/宋体/楷体/黑体/衬线/等宽字体，并修改底色（含自定义选色盘）；已有便签也可调整，自动保存且支持撤销。样式面板默认位于整张便签上方，靠近页面边缘时自动调整位置。`−` 收起成小标记，垃圾桶删除，删除可以撤销。
- **高亮笔记** 附着在高亮的文字上；下划线也支持添加笔记。高亮、下划线完成后不会弹出面板；点击已有标记，再点 **添加笔记**，直接输入并点击 **完成**。有笔记的原文左上角会显示小三点，悬停原文或三点即可预览，此时三点暂时隐藏，移开后恢复；清空笔记后三点消失。预览可以把鼠标移上去停住、滚动看完长笔记，点击预览直接编辑；编辑时底部的 A−/A+ 调整所有高亮笔记的字号。点击原文可继续编辑、换色或删除，不需要打开右侧栏。旧版「原文笔记」自动作为高亮笔记使用，保留内容、颜色和原文位置。
- 选择画笔、箭头或矩形后，在页面拖动绘制。画笔显示随颜色变化的十字准星、圆环和中心点，中心点对应落笔位置，新笔迹进行平滑处理。橡皮擦保留两种模式：**局部擦除**只擦掉擦头经过的部分；**笔画擦除**碰到一笔就擦除这一整笔（之前局部擦除留下的片段也归属于原来的一笔），可连续擦除多笔。笔画模式使用虚线圆形擦头提示；两种模式的一次拖动都可通过一次撤销恢复。高亮、文本注释和便签通过各自的删除按钮删除。
- **激光笔** 用红色发光轨迹临时指示，松开后约 3 秒淡出消失；不会进入批注列表、保存文件或撤销历史。按 `Esc` 可立即清除激光轨迹。
- 画笔和橡皮擦旁的设置按钮可调整笔触粗细、擦头大小，并切换**局部擦除 / 笔画擦除**。擦除方式在切换文件和重启后自动记忆。调节滑块时面板保持打开，点击面板外或在正文落笔时自动收起，第一笔直接生效。画笔模式下按住 `E`，按当前选择的方式临时擦除，松开恢复画笔。`⌘Z` 撤销，`⇧⌘Z` 重做；在便签输入框内，这两个快捷键处理文字编辑。
- 选中文字后，浮动工具条的“高亮 / 划线”只标记这一次选区，保留原来的工具；点击正文空白或“取消文字选择”即清空选区并收起提示。没有选区时，顶部的高亮、下划线按钮仍可进入连续标注模式。
- 从左侧工作空间拖一篇 HTML 或 PDF 到阅读区，就能和当前文章组成 **双栏阅读**，原文件位置不变。首次并排时，拖到左半边就在左栏打开新文章，原文章留在右栏；拖到右半边则相反。已有双栏时，拖到哪一栏就在那一栏打开；拖入已经显示的文章会直接激活对应栏。两栏标题旁的 **×** 分别关闭该篇，另一篇自动恢复单栏；点击哪一栏，顶部工具栏、右侧批注列表、查找和撤销就作用于哪一篇。两栏默认独立滚动、缩放和保存批注。打开工具栏的 **同步滚动** 后，鼠标在任一栏滚动，两篇按相同的屏幕距离一起移动；开启时保留当前位置，可先分别定位再联动。开关状态会记住；关闭后恢复独立滚动。便签内部及嵌入区域的滚动、⌘＋滚轮缩放仍各自独立。拖动中间分隔线调整比例，双击恢复均分。点分隔线顶端的 **⇄**，或把一栏的标题拖到另一侧，两篇文档左右互换，各自的阅读位置和栏宽不变。两篇文档与布局在重启后恢复；关闭一栏只关闭阅读视图，不会删除原文件。源码模式编辑当前文档，切回阅读后恢复双栏。
- 五个常用色使用更深、更鲜明的黄、红、青、蓝和墨色，适用于高亮、手绘、文本注释和便签。旁边的**彩色圆盘**可自由选色，也支持输入 RGB 色值；当前颜色会在切换文件和重启后记住。点击已有高亮或下划线，其颜色菜单同样支持自定义选色，改色可撤销；已有批注保留原色。
- 按 `Esc` 返回文字选择工具。鼠标悬停工具会显示中文名称和使用提示。
- 右侧批注列表显示画笔、箭头和矩形的笔迹缩略图。仅在右侧列表点击条目、缩略图或笔记输入框时，对应批注才显示紫色虚线边框并短暂轻晃；再次点击会重新提示位置。日常新建批注、连续绘画，以及在页面内编辑文字、便签或高亮笔记时均不显示定位虚线。已在视野中的批注不反复滚动页面，远处批注自动定位；边框随滚动、缩放和布局调整跟随。文本注释的边框按实际文字范围计算，随字号和换行更新，不包含编辑框多余的空白。选中条目同时显示淡紫底色和「已选中」。开始下一笔、点击正文空白或按 `Esc` 后取消选中；系统启用减少动态效果时保留边框而不晃动。
- 右侧 **批注** 可编辑每条标记的想法、搜索批注、点击回到原文。**笔记** 用于整篇文档的独立笔记：阅读和书写在同一页，边写边排版，不用懂 Markdown。顶部按钮可设段落样式（正文、标题）、加粗、斜体、删除线、列表、编号、待办、引用和字号，面板窄时放不下的按钮收进末尾的 ⌄；工具栏随笔记字号一起缩放。字号：选中文字点 **Aa** 选小、标准、大、较大、特大（`⌘⇧>` / `⌘⇧<` 逐级调整），大小相对笔记字号，跟着 A− / A+ 一起缩放；**+** 插入代码块、公式、分割线、表格和图片；在空行输入 `/` 也能按名字插入。回车延续列表和引用，在空的一项上再按回车即结束；Tab / Shift+Tab 调整列表层级，行首退格去掉该行格式。光标进入加粗、链接或公式时显示其原始写法，便于修改；熟悉 Markdown 的话也可以直接输入 `#`、`- `、`**` 等。写到底部时页面会自动上移，让正在写的那行停在面板中部，笔记末尾之后也能继续往下滚。底部的 A− / A+ 调整笔记字号（11–24），对所有文档生效并会记住。从笔记复制出去的是纯文字（不带 `**`、`#` 等符号，表格变成 Tab 分隔），在笔记之间复制粘贴则保留格式。笔记仍以 Markdown 保存，AI 回答和白板存入笔记、导出都不受影响；**目录** 根据 h1/h2/h3 生成跳转导航。
- 缩放默认适合宽度：HTML 铺满整个阅读区，按原网页的响应式样式排版，网页两侧留白也可以画线、贴便签。百分比缩放像浏览器一样调整大小并重新排版，两侧面板可收起，留出阅读空间。便签在收窄窗口后仍可访问，恢复宽度后回到原位置。
- 阅读时按 **Tab**，在最近使用的两个工具间来回切换，例如便签与画笔。临时按住 `E` 擦除不改变工具历史。刚贴好便签或正在输入页面批注时，Tab 会结束输入并立即切换工具，内容保留，不会跳到调整大小按钮。普通表单、侧栏笔记和源码编辑器保留正常的 Tab 操作。
- 正文内的 `⌘A` 仍可全选文章；点击页面空白或按 `Esc` 可清除选区。应用工具栏和面板文字不会被意外全选。
- 按住 **⌘（Command）+ 鼠标滚轮** 连续缩放正文：向上滚动放大，向下滚动缩小，范围 **25%–400%**；松开 ⌘ 后恢复普通滚动。双栏时只缩放鼠标所在的一栏，工具栏显示实际百分比。缩放尽量保持指针下的文字位置；选择“适合宽度”可恢复默认。每篇文档的缩放比例会在重启后保留。
- 工作空间支持从访达拖入文件或文件夹；点击目标文件夹后按 **⌘V** 粘贴访达中复制的文件，也可右键选择“粘贴文件”。点击项目名称或文件树空白处，以根目录为目标。导入使用复制，同名文件自动另存副本；原文件保留。
- 批注、笔记和阅读位置自动保存。右下角显示阅读进度。
- 批注不会自动打开右侧栏；侧栏仅由你手动开关，关闭状态在重启后仍然保留。可以收起侧栏，全屏专注阅读和页面批注。
- 右侧导出按钮可导出 Markdown 笔记及批注摘录。手绘在 Markdown 中以标记说明呈现，图形原始数据随项目保存。

## PDF 阅读与批注

在工作空间点击 PDF 即可打开。PDF 使用红色文档图标，与 HTML 和文件夹区分。

- 连续滚动阅读、适合宽度、百分比缩放与 `⌘ + 滚轮`；正文底部的小浮条可输入页码跳转，与 HTML 并排时阅读区顶部对齐。右侧目录显示 PDF 书签，没有书签时按页导航。文内链接和引用支持跳转，查找可搜索尚未滚动到的页面。
- 有文字层的 PDF 可选字、复制、高亮、划线并添加悬停笔记。画笔、箭头、矩形、文本注释、便签、激光笔、两种橡皮擦和撤销沿用 HTML 的交互。已有 PDF 标记随原页显示，已有文字备注可点击查看。
- 批注按页记录位置，缩放、调整布局和重启后仍跟随原页。PDF 与 HTML、PDF 与 PDF 均可拖拽组成双栏，各栏独立阅读和批注。
- 加密文件会提示输入密码，密码不会保存。扫描件或无文字层页面可以画线、贴便签和添加文本注释；当前不提供 OCR。

PDF 原文件保持不变，新增批注和笔记自动保存到 PDF 所在文件夹的 `.html-reader` 中。备份时请连同这一目录一起复制。当前不编辑 PDF 正文，也不将新增批注嵌入或导出为 PDF；可使用现有的 Markdown 笔记导出。

## 编辑 HTML

点击 **源码**，左侧是带语法高亮、查找和撤销的源码编辑器，右侧是实时预览。编辑后预览自动更新，修改默认自动写回原 HTML；关掉源码工具栏的 **自动保存** 后，用 `⌘S` 或保存按钮手动写回。

写回前会自动备份修改前的文件，连续编辑时最多每 10 分钟一份。源码工具栏的 **历史版本** 列出这些备份，可以按页面或源码预览，一键恢复；恢复前会先备份当前内容，所以恢复本身也能撤回。旧备份自动清理：2 小时内全部保留，24 小时内每小时留一份，30 天内每天留一份，更早的删除；每篇文档的备份最多占 200 MB。

如果文件被外部程序改动，应用会阻止覆盖，保留编辑器中的草稿并提示你合并。可以先复制草稿，再用源码工具栏的重新载入按钮载入磁盘版本。

关闭文件、切换文件夹或退出应用时，未保存的源码修改会提示确认。高亮按文字与前后文重新定位：原文被删掉时，笔记仍保留并显示“原文已变化”。点击 **重新关联**，选择新的原文，再点击浮动工具条的 **关联此批注** 即可修复。

当前提供源码编辑与实时预览；尚未实现任意 HTML 的所见即所得排版编辑。

## AI 助手

页间可以接入你自己的 AI 服务，按用量向服务商付费，页间不经手。打开 **AI 设置**（macOS：菜单“页间 → AI 设置…”或 `⌘,`；Windows：菜单“文件 → AI 设置…”或 `Ctrl+,`；也可以点右侧栏“助手”里的设置按钮），选择服务商，填入在它官网申请的 API Key。

支持 DeepSeek、通义千问、Kimi、智谱 GLM、豆包（火山方舟）、小米 MiMo、硅基流动、Claude、OpenAI、Gemini、OpenRouter 和任何 OpenAI 兼容接口，也支持在本机运行的 Ollama、LM Studio。填好 Key 后可以获取模型列表、测试连接；可以添加多个服务，在助手输入框下方切换。

**用 ChatGPT 账号**：选“Codex”，不需要 API Key，用的是 ChatGPT 套餐里的 Codex 额度，不另外付费。它通过这台电脑上的 Codex（ChatGPT 桌面版自带，也可以单独安装 Codex 命令行工具）连接：页间用 OpenAI 为第三方应用提供的 Codex App Server 接口，沿用 Codex 已有的登录，没登录时可以在设置里直接“用 ChatGPT 登录”。页间碰不到账号凭据，并关闭了 Codex 自带的命令行、插件等工具，只让它回答问题或调用页间自己的工具；联网搜索只在助手提问时打开。额度有 5 小时和每周上限，助手里每条回答的提示中会显示已用比例；回答比直接用 API 慢几秒。Claude 的网页账号不能这样用：Anthropic 不允许第三方应用使用 Claude 订阅登录。

**用 Kimi 会员**：选“Kimi Code”，不需要 API Key，用的是 Kimi 会员里的 Kimi Code 额度，不另外付费。Kimi 只允许编程工具使用会员额度，会员的 `sk-kimi-` Key 填在“Kimi”里会被拒绝，所以页间通过这台电脑上的 Kimi Code CLI 连接：先按 [Kimi Code 官网的说明](https://www.kimi.com/code/docs/kimi-code-cli/guides/getting-started.html)安装，再在设置里“用 Kimi 账号登录”。页间用 CLI 为编辑器提供的 ACP 接口；CLI 的登录和会话放在页间自己的数据目录里，和你自己用的 Kimi Code 互不影响。Kimi Code 自带的命令行、读写文件和联网工具都关闭，只让它回答问题或调用页间自己的工具。设置里会显示 5 小时和每周额度的已用比例；回答比直接用 API 慢几秒。

- **问这篇文档**：点阅读工具栏的 **AI 助手与笔记**，在面板中选择 **助手**；再次点击工具栏按钮可收起侧栏。回答里的小编号是原文引用，点击会跳到原文并短暂标出，也可以把这句直接高亮；原文中找不到的引用会划掉，提醒可能是模型改写的。选中文字后提问，会针对选中的部分回答；双栏阅读时同时参考两篇。回答可以复制，或存入文档笔记。
- **快捷操作**：总结全文、AI 划重点、整理我的批注、出几道思考题，双栏时还可以对比两篇文档。AI 划重点直接在原文加高亮，按类型着色、附一句说明，批注列表里标着“AI”；不满意按一次 `⌘Z` 全部撤销。
- **制作精读笔记**：助手里的“制作精读笔记”会为当前论文或文章写一份伴读 HTML：一句话概括、背景与问题、方法分步讲解（含公式和符号说明）、关键概念、实验结果表、原文金句、贡献与局限、读后思考题。它保存在原文旁边（`论文名-精读笔记.html`），并排在右栏打开；笔记里的页码可以点，PDF 会跳到对应页。它是普通的 HTML 文档，可以照常批注和修改。长论文会先分段通读再写。
- **全文翻译**：助手里的“全文翻译”把当前论文或文章逐段译成中文，存成原文旁边的 `论文名-译文.html`，并排在右栏打开。译文页面一开始就打开。先译开头一部分，顺带定下标题和术语的译法（术语对照放在译文开头）；其余部分照着这张表同时翻译，译好的部分每隔几秒补上一次。某一部分漏译了原文里成段的内容，会单独补译，放回原来的位置。鼠标移到译文段落上，左边会出现页码，点它 PDF 会跳到原文这一段并短暂标出。译文和它的 PDF 并排、工具栏的 **同步滚动** 打开时，两边按段落对齐着一起滚，不再按相同的距离滚；页间打开译文时会顺手打开同步滚动。PDF 里的图按图注从原页面裁下来，放在中文图注的位置；表格照原表的行和列重排成中文表格（页间先从 PDF 上按位置读出每个单元格交给 AI，模型名、数据集名、指标这类专有名词保留原文，数字照抄），表格下面可以展开原表截图核对。译文是一个文件，发给别人也能直接看。参考文献照抄原文放在文末，正文里的 [12] 点一下就跳到那一条。章节层级按编号统一，开头有可展开的目录；被图表隔断的段落会接回去，两部分接缝处重复的译文会去掉。公式按上下文还原后显示。以前译好、还没有图的译文，再点“全文翻译”选“打开已有译文”，会从原文补上图表。中途可以停下，点「接着翻」只翻剩下的部分。译过的文档再点“全文翻译”，会先问是打开已有译文还是重新翻译；很长的文档会先说大概要用多少 token。用的是助手输入框下方选的模型，和精读笔记一样；通过 Codex、Kimi Code 时一次翻一部分，会慢一些。
- **划词**：选中文字后，浮动工具条上的 **解释**、**翻译**、**提问**。结果可以存为高亮笔记，或转到助手里继续追问。
- **白板讲解**（原型）：白板收起后，阅读工具栏的白板按钮会显示页老师的回答进度，点击即可回到当前白板。选中文字后点浮动工具条上的 **白板**；要讲公式、图表或截图，点工具栏的白板按钮，在页面上框选一块区域（需要能看图的模型）；和文档无关的题目，框选时点 **不框选，打开空白白板**，直接提问。提问时可以点输入框旁的 **添加附件**，选择或拖入 PDF、TXT、Markdown（`.md` / `.markdown`）、HTML（`.html` / `.htm`）和图片，也可以直接粘贴图片。附件读取完成后可查看文件名、读取范围或移除；不写问题直接发送，会讲解附件的主要内容。图片会放到白板上，文档内容随提问保存在白板记录中，重新打开后可以接着追问。页老师边说边写：字幕是它说的话，同时写板书、公式和代码（保留缩进，带行号），在白板上的画布里一笔一笔地画示意图、结构图、数组、链表、树和简笔画，画函数图像和空间坐标系里的曲线、曲面（它只写表达式，点由页间算出来），也能擦掉画过的东西再画，比如演示指针移动。它用圈、划线、荧光笔、箭头和旁注指着讲，逐行讲代码时有一个跟着走的高亮，也能圈出图片里的某一部分。讲的途中直接用笔在白板上圈出或划出没懂的地方，页老师会先停下；在下方说哪里不懂并发送，页老师会指着你标的地方换个说法重讲，写在你的问题下面。可以暂停（空格）、切换 1× / 1.5× / 2× 速度、查看字幕记录，`⌘Z` 撤回自己的笔迹。字幕栏右边的 **讲解方式** 有三种：**静音讲解**（只看字幕和板书）；**页老师出声**，页老师用系统的中文语音边说边画，你打字提问；**语音对话**，像打电话一样直接开口说，页老师在讲的时候你一开口他就停下来听，说完自动发给他，你说「继续」他就接着讲。macOS 上使用系统声音时，语音合成和识别都在本机完成，不上传录音，外放时靠系统的回声消除分辨你和页老师的声音，戴耳机更清楚。Windows 上默认用通义实验室的 SenseVoice 模型在本机识别，不上传录音，第一次语音对话时下载约 240MB 的模型；填了通义百炼或豆包语音的 Key，也可以在面板里改成由它们识别，按时长计费；用电脑自带的声音外放时，页老师的声音可能被当成你在说话，戴耳机更好。第一次语音对话会请求麦克风权限，面板里可以换页老师的声音（在系统设置里下载的“高级”中文语音也会出现在这里）。能看图的模型还会收到一张白板截图。讲过的白板自动保存在项目的 `.html-reader/boards` 中：白板标题栏或工具栏白板按钮里的 **白板记录** 列出本项目的全部白板，打开后可以接着提问，也可以删除。每块白板都能 **重看讲解**：字幕和板书按原来的节奏再走一遍，进度条可以拖到任意一句，重看不消耗 AI 额度；页老师用语音服务讲的句子也随白板保存，重看时不再向语音服务要一遍。
- **免费在线声音**：在 AI 设置的「语音服务」里可直接试听 **Edge TTS（推荐）**，无需注册或填写 API Key，默认使用晓晓；在白板「出声」菜单的「页老师的声音」里选择晓晓、晓伊、云希、云健、云扬、云夏、东北话晓北或陕西话晓妮。支持原有的暂停、调速和白板回放，已保存的讲解声音重看时不用再次合成。朗读文字会直接发给微软的在线语音服务，Mac 和 Windows 均无需安装 Python 或 Edge 浏览器。此非官方免费通道可能限流、变更或停用，断线、超时或临时服务错误会自动重试两次（通常间隔 1 秒、2 秒；有服务端等待要求时按其要求等待）。仍失败时停在当前句，显示错误，可点「重试本句」或换声音，不会跳过字幕和讲解；它不提供语音识别，白板讲解本身的模型和会员要求照旧。
- **白板附件范围**：每次最多 4 份文档和 6 张图片。PDF 单份不超过 20 MB，文本 / Markdown / HTML 不超过 2 MB；正文及 PDF 全部页面完整读取，不再按字数或页数截断。能放入所选模型上下文的文档直接发送全文；超长资料逐段读取后综合讲解，显示阅读进度，所有分段处理完成后才回答，失败会提示重试。原文随白板记录完整保存，追问时可以重新读取；分段笔记是整理结果，不是逐字复述。PDF 提取全部文字，无文字页面全部作为图片按批次读取（需要能看图的模型）；有文字页面里的图表可另附截图。加密 PDF 需先解锁。HTML 读取静态正文，保留标题、列表、表格和代码，不执行脚本或加载网页资源；网页图片和动态内容可另附截图。
- **源码 AI 修改**：源码模式下点“AI 修改”，描述想怎么改。先看改动对比，右侧预览显示修改后的效果，确认后才写入源码；写入前的版本照常自动备份，也可以在编辑器中撤销。
- **整个项目**：在助手里切换到“整个项目”，AI 会自己阅读、搜索项目中的文档，帮你添加高亮、写文档笔记、修改或新建 HTML。每个修改都先显示预览，点“应用”才执行，也可以跳过；不能删除或移动文件，也访问不到项目以外的文件。
- **联网搜索**：在助手里提问（“本文”和“整个项目”）时，Claude、DeepSeek、通义千问、Kimi、智谱 GLM、小米 MiMo、OpenRouter 和 Codex 可以联网（DeepSeek 只有它的 Anthropic 兼容接口能搜，页间提问时自动改走那里，Key 不用换）。要不要搜由模型判断：问到最新的消息、版本、价格，或要核实没把握的事实时才搜，用了搜索结果会注明来源。搜索的内容显示在回答的步骤里；通义千问的接口不告诉页间搜了什么，所以只看得到回答。搜索用的是各家自己的服务，填好的 Key 就能用，按次另外计费。解释、翻译、白板等功能不联网。
- **找论文**：在“整个项目”里说“找一篇某领域的论文，下载到某个文件夹”，AI 会查找论文，看标题、作者、出处、被引次数和摘要挑出合适的，再把公开的 PDF 下载到你指定的文件夹（不存在会自动新建）。各学科都能查：[OpenAlex](https://openalex.org) 收录所有学科（医学、经济、法学、人文社科等），每次都会查；医学、生命科学和心理学会加查 [PubMed](https://pubmed.ncbi.nlm.nih.gov)（经 Europe PMC），理工科和经济学会加查 arXiv，AI 也会只保留这个学科的论文。也可以指定去哪查，比如“只在 PubMed 里找”“只要 Nature 和 The Lancet 上的”。知网、万方、Google Scholar、Web of Science 等没有公开接口，这里查不了，AI 会直接告诉你；可以自己下载 PDF 放进项目，或把 PDF 链接发给 AI 下载。下载前会显示论文标题和链接，点“应用”才下载。任何支持工具调用的模型都能用，不需要另外的 Key；查找时只把关键词发给这几个论文库。OpenAlex 不填 Key 时，同一网络（同一个校园网、公司网络或代理）的人共用每天的免费额度，用完后会提示“暂时繁忙”；可以在 OpenAlex 免费申请一个 Key，填到 AI 设置的「论文检索」里，保存时会先向 OpenAlex 核对，Key 只发给 OpenAlex。有些出版社的链接需要登录或会拦截下载，这时 AI 会换一个链接或换一篇。在“本文”里提这种要求，AI 会提醒你切换到“整个项目”。
- 长文档超出模型一次能处理的长度时，只发送开头和与问题最相关的部分；总结和划重点会分段处理。解释、翻译、白板等功能可以在 AI 设置的「各功能的模型」里单独选服务、模型和推理强度；选的档位原样使用，不会被自动调低。
- 对话按文档保存，下次打开还在；“整个项目”的对话单独保存。
- 助手记得整段对话：之前的问答、没写完就停下或断开的回答、生成过的精读笔记都会一起交给模型，聊到一半换模型、换服务也能接着聊。对话长到放不下时，较早的部分会自动压缩成摘要再接着聊。文档长到放不下时，模型先拿到开头，需要别的部分时自己搜索、翻到对应的页再回答，步骤显示在回答上方；最多查 15 轮，查满了就根据已经查到的内容回答。
- 一段对话同时只回答一个问题。精读笔记写到一半停下或断开时，点「接着写」或直接说“继续”，会从断开的地方写完。历史对话列表里，正在回答的对话前面有转圈图标，在别的对话里时回答完成的会标一个小点。

隐私：API Key 只保存在这台电脑上（Windows 用系统加密保存；macOS 保存在只有当前用户能读取的应用数据文件夹），只发送给对应的服务商。第一次使用某个服务时，会先询问是否同意把文档内容发送给它。可以在 AI 设置中为某个项目停用 AI；使用本机模型时，文档不会离开电脑。

## 数据在哪里

AI 请求诊断保存在应用数据目录的 `logs/ai.jsonl`（macOS：`~/Library/Application Support/页间/logs/ai.jsonl`，Windows：`%APPDATA%\页间\logs\ai.jsonl`）。每次请求记录结束状态；OpenAI 兼容接口（包括智谱 GLM）还会逐次记录 HTTP 状态、服务端请求标识、原始 `finish_reason`、是否收到 `[DONE]`、是否读到流结束、输出上限、字符数、Token 用量（服务返回时）和耗时。日志不保存对话正文、思考内容、工具参数、API Key 或原始响应。超过 2 MB 自动轮换，只留一份 `ai.jsonl.1` 旧日志。字段含义和排查方式见 [AI 诊断日志说明](docs/ai-diagnostics.md)。

语音诊断保存在应用数据目录的 `logs/speech.jsonl`（macOS：`~/Library/Application Support/页间/logs/speech.jsonl`）。记录每次尝试的时间、耗时、状态码、网络错误码、重试与取消结果，以及白板和句子的哈希标识；缓存保存失败单独标记。日志不保存朗读原文、音频或 API Key，超过 2 MB 自动轮换，只留一份旧日志。

每篇文档的批注保存在它所在文件夹的隐藏 `.html-reader` 中，打开上级或下级工作空间都使用同一份批注。标签页与布局单独保存在当前工作空间根目录的索引中：

```text
你的项目/
  文章.html
  论文.pdf
  图片与样式等资源/
  .html-reader/
    workspace.json          # 文档身份、路径和打开的标签页
    documents/<文档ID>.json  # 批注、画笔轨迹、笔记、位置、缩放
    backups/<文档ID>/*.html  # 保存源码前的历史版本
    ai/<文档ID>.json         # 与 AI 助手的对话
    ai/project.json          # “整个项目”的对话（在工作空间根目录）
```

首次打开旧文档时，应用会合并父子工作空间中已有的批注；迁移保留原记录及索引备份，后续修改和删除不会重复导入旧批注。

批注不会直接插入原 HTML 或 PDF。备份或搬走整个项目文件夹时，请一起保留各层隐藏的 `.html-reader` 目录。应用内重命名或移动文件会保留文档 ID；外部重命名可在原路径已消失且文件内容未变时恢复关联。

删除通过系统废纸篓（Windows 为回收站）完成，关联的批注仍保留。恢复原文件后可以继续读取笔记。移动 HTML 时，相对图片、CSS、脚本链接仍按新目录解释；应用不会自动重写这些源文件链接。

应用的最近工作空间设置保存在系统的应用数据目录中（macOS 为 `~/Library/Application Support/页间`，Windows 为 `%APPDATA%\页间`）。AI 服务的设置和 API Key 保存在同一目录的 `ai.json`。应用本身不上传文档；只有使用 AI 功能时，相关的文字才会发送给你选择的服务商。激活或试用会员时，激活码和一个由电脑硬件编号算出的匿名编号会发给 helloxxy.com 的激活服务器，会员凭证保存在应用数据目录的 `license.json`；没开通会员时，只在打开会员窗口时连接激活服务器。HTML 里原本引用的远程字体、脚本、图片仍会从对应网站加载。随包演示文档完全离线可用；用户自己的 HTML 若依赖 MathJax 等远程脚本，仍需网络。

## 开发与验证

需要 Node.js 22.13+，推荐使用 Node.js 22。项目包含 `.nvmrc`。

```sh
npm ci
npm run dev        # Vite + Electron 桌面开发
npm run build      # 类型检查、前端与阅读脚本构建
npm start          # 运行已经构建的桌面应用
npm test           # 文件保存、备份、冲突、路径边界等测试
npm run test:e2e   # 真实 Electron 中的交互回归测试
npm run test:pdf  # 单独验证 PDF 阅读、批注、双栏、密码与重启恢复
npm run test:zoom # 单独验证 Command + 滚轮缩放、阅读位置与保存
npm run test:reading # 单独验证拖拽双栏、分栏关闭、Tab 和全选退出
npm run test:annotations # 单独验证便签、局部擦除、中文提示和侧栏状态
npm run test:ai    # 用本地模拟服务验证 AI 设置、问答引用、划重点、划词、源码修改和项目 Agent
npm run pack       # 构建当前架构的 .app
npm run dist:mac   # 构建 Apple 芯片 arm64 的 DMG 和校验文件
npm run dist:win   # 在 Mac 上交叉构建 Windows x64 安装程序和校验文件
```

`npm run dev:web` 提供只用于开发检查的网页入口。系统文件夹选择、访达 / 资源管理器、废纸篓 / 回收站等功能需要桌面版本。不要同时用多个开发实例编辑同一个工作空间。

自动测试使用仓库中的 `samples/` 原创演示文档和测试代码生成的临时文件，不依赖个人资料或外部账号。覆盖本地资源、沙箱隔离、高亮、页面便签、手绘、局部擦除、撤销、笔记、目录、源码保存与备份、重定位、改名、移动、冲突和重启恢复。截图保存在系统临时目录。

开发时可以用 `FOLIO_WORKSPACE=/你的/HTML目录 npm run dev` 指定本地文件夹。额外的本地兼容性测试可设置 `FOLIO_TEST_SAMPLES`，默认不需要。个人阅读材料、批注、备份和本地配置均不进入版本控制或安装包。

## 实现结构

- `electron/workspace.cjs`：文件夹边界检查、文档身份、串行原子写入、备份和冲突检测。
- `electron/main.cjs`：窗口、原生菜单、文件选择、IPC 和文档资源协议。
- `src/pdf/pdf.ts`：PDF.js 页面渲染、文字层、页码、书签与密码处理。
- `src/reader/runtime.ts`：文档内的文字定位、SVG 手绘层与阅读事件。
- `src/hooks/useDocuments.ts`：标签页、草稿、批注历史和持久化队列。
- `src/components/`：文件树、工具栏、阅读区、源码编辑器、批注笔记栏、AI 助手与设置。
- `src/themes.css` 与 `src/theme.ts`：界面主题的颜色变量、主题列表、跟随系统与窗口底色同步。
- `electron/ai-providers.cjs`：OpenAI 兼容接口与 Claude（Anthropic SDK）两种协议的流式请求、工具调用和错误说明。
- `electron/ai.cjs`：AI 服务设置、API Key 保存与请求管理。Key 只在主进程中使用，界面拿不到。
- `electron/ai-codex.cjs`：通过本机 Codex App Server 使用 ChatGPT 账号：启动与登录、流式回答，以及把项目 Agent 的工具交给 Codex 调用。App 开着时，一段对话保留同一个 Codex 线程，每次只发新的内容；对话改变了（压缩成摘要、文档变了）就用页间存的对话记录重建。
- `electron/ai-kimi.cjs`：通过本机 Kimi Code CLI 的 ACP 接口使用 Kimi 会员：登录、模型与额度、流式回答，以及用本机的 MCP 接口把项目 Agent 的工具交给 Kimi 调用。和 Codex 一样，一段对话保留同一个会话；退出 App 时留下的会话，下次启动 CLI 时删除。
- `electron/hearing.cjs`、`electron/hearing-worker.cjs`、`electron/cloud-hearing.cjs`：没有 macOS 语音 helper 时（Windows）的语音对话识别：界面打开麦克风，子进程用 Silero VAD 判断什么时候在说话，再用 SenseVoice 在本机识别，或交给通义百炼 / 豆包语音的流式识别。
- `src/ai/`：对话与项目 Agent、文档上下文与长文档分段、原文引用定位、源码修改的解析与对比。
- `electron/license.cjs`、`src/license.ts`、`server/folio-license.mjs`：会员。主进程向激活服务器激活、续期，用内置公钥校验服务器签名的会员凭证；PDF 文档和 AI 请求在主进程里先检查会员，界面在入口处弹出会员窗口。

AI 读取文档用的是阅读区本身：打开的文档直接取渲染后的文字，没打开的在隐藏的阅读区中载入，所以 AI 标出的高亮与手动高亮的定位方式完全相同。

文档在独立沙箱 iframe 中运行，无法直接访问文件系统接口。文件操作只允许在当前项目范围内进行。源码编辑器按需加载，阅读界面无需先加载编辑器。

本版本支持 PDF 阅读与批注，并优先支持本地 UTF-8 静态 HTML、常见网页脚本、相对资源与公式。复杂网页应用、登录网站、嵌套网页、canvas 内部的文字批注、跨设备同步和 PDF 式分页导出不在当前版本范围内。页面大幅改版后，跨多个段落的自由手绘可能需要重新绘制。
