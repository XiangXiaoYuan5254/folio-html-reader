# 页间 · Folio

一个本地 HTML / PDF 阅读工作空间。像 IDE 一样打开文件夹，像 PDF 阅读器一样做高亮、批注、手绘和笔记，同时编辑 HTML 源码。

## 下载与安装

[**下载最新版本**](https://github.com/XiangXiaoYuan5254/folio-html-reader/releases/latest) · [提交问题](https://github.com/XiangXiaoYuan5254/folio-html-reader/issues)

支持 **macOS 12 及以上（Apple 芯片）** 和 **Windows 10 / 11（64 位）**，无需 Node.js、终端或单独启动服务器。

| 你的电脑 | 下载文件 |
| --- | --- |
| Mac（Apple 芯片，M 系列） | `Folio-版本号-mac-arm64.dmg` |
| Windows 10 / 11（64 位） | `Folio-版本号-win-x64-setup.exe` |

### macOS

1. 打开下载的 DMG，把 **页间** 拖到 **Applications / 应用程序**。
2. 复制完成后推出磁盘映像，在“应用程序”或 Spotlight 中打开页间。
3. 点击左侧 **打开文件夹**，选择存放 HTML 或 PDF 的文件夹。首次启动提供三篇可自由编辑的原创演示文档。

当前版本采用本地签名，**尚未取得 Apple Developer ID 签名和 Apple 公证**。如果 macOS 提示无法验证开发者，请先尝试打开一次，再到 **系统设置 → 隐私与安全性 → 仍要打开**。只对已确认来自本仓库发布页的应用执行此操作。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

Mac 的芯片型号可在苹果菜单的“关于本机”中查看。Intel 芯片的 Mac 暂不支持。

### Windows

1. 运行下载的 `Folio-版本号-win-x64-setup.exe`，按向导完成安装。默认只为当前用户安装，不需要管理员权限，也可以改安装位置。
2. 从开始菜单或桌面快捷方式打开 **页间**。
3. 点击左侧 **打开文件夹**，选择存放 HTML 或 PDF 的文件夹。

安装后，在资源管理器中右键 HTML 文件，选择 **打开方式 → 页间** 即可直接阅读；安装程序不会更改你的默认浏览器。

安装程序**尚未进行代码签名**。运行时如果 Windows SmartScreen 提示“Windows 已保护你的电脑”，点击 **更多信息 → 仍要运行**。只对已确认来自本仓库发布页的安装包执行此操作。

### 校验与安全

若提示文件损坏或包含恶意内容，请停止安装，重新下载并核对发布页提供的 `SHA256SUMS.txt`。发布包不包含关闭系统安全保护的脚本。

### 更新与备份

页间会在后台下载新版本，下载好后提示重启；选“稍后”的话，下次退出时自动安装。点标题栏的“页间”可以手动检查更新。macOS 上，页间要放在“应用程序”文件夹里才能自动更新。

0.7.0 及更早的版本没有自动更新，需要手动更新一次：

- macOS：先退出旧版，再将新版拖入“应用程序”并选择替换。
- Windows：退出页间后运行新版安装程序，会直接覆盖旧版。

阅读项目与批注数据独立于应用；更新前可备份整个阅读文件夹，记得包含隐藏的 `.html-reader`。

## 阅读与批注

- 工具栏右侧的 **专注阅读** 或 `⌘⇧F`（Windows 为 `Ctrl+Shift+F`）进入全屏阅读，隐藏标签页、工作空间和批注栏。鼠标移到顶部或点击右上角 **工具** 可呼出批注工具，回到正文落笔后自动收起；`Esc`、`⌘⇧F` 或 **退出专注** 返回原布局，双栏与批注保留。
- 保存状态位于左侧工作空间底部；点击旁边的 **?** 查看当前工具提示、快捷键、批注数量和阅读进度。阅读区不再占用整行底部状态栏。
- 左侧项目树与正文之间的分隔线可以左右拖动调整宽度，悬停显示调整光标；双击恢复默认宽度。调整后自动记住宽度，切换文件和重启仍保留；窗口变窄时临时限制目录宽度，恢复窗口后沿用你的设置。
- 左侧项目树可递归浏览文件夹、搜索文件、新建 HTML 和文件夹。文件夹使用暖黄色图标，HTML 文件使用蓝色图标，展开与折叠也有不同的文件夹图标。支持拖拽文件和文件夹到目标文件夹，悬停约半秒自动展开；拖到项目名称或列表空白处可移回根目录。文件仍按名称排序，拖拽改变实际所在文件夹。移动会保留批注、阅读标签和未保存的源码草稿；同名目标不会被覆盖。悬停在文件行右侧的 `…` 可重命名、移动、移到废纸篓或在 Finder 中显示（Windows 上为回收站和资源管理器）。
- 选中文字后，使用浮动工具条添加高亮或下划线。也可以先选工具，再拖选文字。
- **文本注释（T）** 是直接写在页面上的文字，背景透明，和便签分开。点击页面即可输入，悬停或编辑时显示移动标题、字号和删除控件；右下角调整文字宽度，点击勾号完成编辑。文字会随输入自动保存。
- 点击 **便签** 工具后，在页面任意位置单击，直接输入想法。拖动便签标题可以移动，拖动右下角可以调整大小；新便签自动沿用上次手动调整的尺寸，切换文档和重启应用后也会记住，已有便签保留各自大小。便签右上角的 **样式** 按钮可调整字号、切换系统字体/宋体/楷体/黑体/衬线/等宽字体，并修改底色（含自定义选色盘）；已有便签也可调整，自动保存且支持撤销。样式面板默认位于整张便签上方，靠近页面边缘时自动调整位置。`−` 收起成小标记，垃圾桶删除，删除可以撤销。
- **高亮笔记** 附着在高亮的文字上；下划线也支持添加笔记。高亮、下划线完成后不会弹出面板；点击已有标记，再点 **添加笔记**，直接输入并点击 **完成**。有笔记的原文左上角会显示小三点，悬停原文或三点即可预览，此时三点暂时隐藏，移开后恢复；清空笔记后三点消失。点击原文可继续编辑、换色或删除，不需要打开右侧栏。旧版「原文笔记」自动作为高亮笔记使用，保留内容、颜色和原文位置。
- 选择画笔、箭头或矩形后，在页面拖动绘制。画笔显示随颜色变化的十字准星、圆环和中心点，中心点对应落笔位置，新笔迹进行平滑处理。橡皮擦保留两种模式：**局部擦除**只擦掉擦头经过的部分；**笔画擦除**碰到一笔就擦除这一整笔（之前局部擦除留下的片段也归属于原来的一笔），可连续擦除多笔。笔画模式使用虚线圆形擦头提示；两种模式的一次拖动都可通过一次撤销恢复。高亮、文本注释和便签通过各自的删除按钮删除。
- **激光笔** 用红色发光轨迹临时指示，松开后约 3 秒淡出消失；不会进入批注列表、保存文件或撤销历史。按 `Esc` 可立即清除激光轨迹。
- 画笔和橡皮擦旁的设置按钮可调整笔触粗细、擦头大小，并切换**局部擦除 / 笔画擦除**。擦除方式在切换文件和重启后自动记忆。调节滑块时面板保持打开，点击面板外或在正文落笔时自动收起，第一笔直接生效。画笔模式下按住 `E`，按当前选择的方式临时擦除，松开恢复画笔。`⌘Z` 撤销，`⇧⌘Z` 重做；在便签输入框内，这两个快捷键处理文字编辑。
- 选中文字后，浮动工具条的“高亮 / 划线”只标记这一次选区，保留原来的工具；点击正文空白或“取消文字选择”即清空选区并收起提示。没有选区时，顶部的高亮、下划线按钮仍可进入连续标注模式。
- 从左侧工作空间拖一篇 HTML 或 PDF 到阅读区，就能和当前文章组成 **双栏阅读**，原文件位置不变。首次并排时，拖到左半边就在左栏打开新文章，原文章留在右栏；拖到右半边则相反。已有双栏时，拖到哪一栏就在那一栏打开；拖入已经显示的文章会直接激活对应栏。也可以点击标签栏右侧的“双栏阅读”。两栏标题旁的 **×** 分别关闭该篇，另一篇自动恢复单栏；点击哪一栏，顶部工具栏、右侧批注列表、查找和撤销就作用于哪一篇。两栏默认独立滚动、缩放和保存批注。打开工具栏的 **同步滚动** 后，鼠标在任一栏滚动，两篇按相同的屏幕距离一起移动；开启时保留当前位置，可先分别定位再联动。开关状态会记住；关闭后恢复独立滚动。便签内部及嵌入区域的滚动、⌘＋滚轮缩放仍各自独立。拖动中间分隔线调整比例，双击恢复均分。两篇文档与布局在重启后恢复；“退出双栏”保留当前文档。源码模式编辑当前文档，切回阅读后恢复双栏。
- 五个常用色使用更深、更鲜明的黄、红、青、蓝和墨色，适用于高亮、手绘、文本注释和便签。旁边的**彩色圆盘**可自由选色，也支持输入 RGB 色值；当前颜色会在切换文件和重启后记住。点击已有高亮或下划线，其颜色菜单同样支持自定义选色，改色可撤销；已有批注保留原色。
- 按 `Esc` 返回文字选择工具。鼠标悬停工具会显示中文名称和使用提示。
- 右侧批注列表显示画笔、箭头和矩形的笔迹缩略图。仅在右侧列表点击条目、缩略图或笔记输入框时，对应批注才显示紫色虚线边框并短暂轻晃；再次点击会重新提示位置。日常新建批注、连续绘画，以及在页面内编辑文字、便签或高亮笔记时均不显示定位虚线。已在视野中的批注不反复滚动页面，远处批注自动定位；边框随滚动、缩放和布局调整跟随。文本注释的边框按实际文字范围计算，随字号和换行更新，不包含编辑框多余的空白。选中条目同时显示淡紫底色和「已选中」。开始下一笔、点击正文空白或按 `Esc` 后取消选中；系统启用减少动态效果时保留边框而不晃动。
- 右侧 **批注** 可编辑每条标记的想法、搜索批注、点击回到原文。**笔记** 用于整篇文档的独立笔记，支持直接写 Markdown 文本；**目录** 根据 h1/h2/h3 生成跳转导航。
- 缩放默认适合宽度：HTML 铺满整个阅读区，按原网页的响应式样式排版，网页两侧留白也可以画线、贴便签。百分比缩放像浏览器一样调整大小并重新排版，两侧面板可收起，留出阅读空间。便签在收窄窗口后仍可访问，恢复宽度后回到原位置。
- 阅读时按 **Tab**，在最近使用的两个工具间来回切换，例如便签与画笔。临时按住 `E` 擦除不改变工具历史。刚贴好便签或正在输入页面批注时，Tab 会结束输入并立即切换工具，内容保留，不会跳到调整大小按钮。普通表单、侧栏笔记和源码编辑器保留正常的 Tab 操作。
- 正文内的 `⌘A` 仍可全选文章；点击页面空白或按 `Esc` 可清除选区。应用工具栏和面板文字不会被意外全选。
- 按住 **⌘（Command）+ 鼠标滚轮** 连续缩放正文：向上滚动放大，向下滚动缩小，范围 **25%–400%**；松开 ⌘ 后恢复普通滚动。双栏时只缩放鼠标所在的一栏，工具栏显示实际百分比。缩放尽量保持指针下的文字位置；选择“适合宽度”可恢复默认。每篇文档的缩放比例会在重启后保留。
- 工作空间支持从访达拖入文件或文件夹；点击目标文件夹后按 **⌘V** 粘贴访达中复制的文件，也可右键选择“粘贴文件”。点击项目名称或文件树空白处，以根目录为目标。导入使用复制，同名文件自动另存副本；原文件保留。
- 批注、笔记和阅读位置自动保存。右下角显示阅读进度。
- 批注不会自动打开右侧栏；侧栏仅由你手动开关，关闭状态在重启后仍然保留。可以收起侧栏，全屏专注阅读和页面批注。
- 右侧导出按钮可导出 Markdown 笔记及批注摘录。手绘在 Markdown 中以标记说明呈现，图形原始数据随项目保存。

## PDF 阅读与批注

在工作空间点击 PDF 即可打开。PDF 使用红色文档图标，与 HTML 和文件夹区分。

- 连续滚动阅读、适合宽度、百分比缩放与 `⌘ + 滚轮`；正文底部的小浮条可输入页码跳转，与 HTML 并排时阅读区顶部对齐。右侧目录显示 PDF 书签，没有书签时按页导航。文内链接和引用支持跳转，查找可搜索尚未滚动到的页面。
- 有文字层的 PDF 可选字、复制、高亮、划线并添加悬停笔记。画笔、箭头、矩形、文本注释、便签、激光笔、两种橡皮擦和撤销沿用 HTML 的交互。已有 PDF 标记随原页显示，已有文字备注可点击查看。
- 批注按页记录位置，缩放、调整布局和重启后仍跟随原页。PDF 与 HTML、PDF 与 PDF 均可拖拽组成双栏，各栏独立阅读和批注。
- 加密文件会提示输入密码，密码不会保存。扫描件或无文字层页面可以画线、贴便签和添加文本注释；当前不提供 OCR。

PDF 原文件保持不变，新增批注和笔记自动保存到 PDF 所在文件夹的 `.html-reader` 中。备份时请连同这一目录一起复制。当前不编辑 PDF 正文，也不将新增批注嵌入或导出为 PDF；可使用现有的 Markdown 笔记导出。

## 编辑 HTML

点击 **源码**，左侧是带语法高亮、查找和撤销的源码编辑器，右侧是实时预览。编辑后预览自动更新；`⌘S` 或保存按钮写回原 HTML。

写回前会自动备份修改前的文件，连续编辑时最多每 10 分钟一份。源码工具栏的 **历史版本** 列出这些备份，可以按页面或源码预览，一键恢复；恢复前会先备份当前内容，所以恢复本身也能撤回。旧备份自动清理：2 小时内全部保留，24 小时内每小时留一份，30 天内每天留一份，更早的删除；每篇文档的备份最多占 200 MB。

如果文件被外部程序改动，应用会阻止覆盖，保留编辑器中的草稿并提示你合并。可以先复制草稿，再用源码工具栏的重新载入按钮载入磁盘版本。

关闭文件、切换文件夹或退出应用时，未保存的源码修改会提示确认。高亮按文字与前后文重新定位：原文被删掉时，笔记仍保留并显示“原文已变化”。点击 **重新关联**，选择新的原文，再点击浮动工具条的 **关联此批注** 即可修复。

当前提供源码编辑与实时预览；尚未实现任意 HTML 的所见即所得排版编辑。

## 数据在哪里

每篇文档的批注保存在它所在文件夹的隐藏 `.html-reader` 中，打开上级或下级工作空间都使用同一份批注。标签页与布局单独保存在当前工作空间根目录的索引中：

```text
你的项目/
  文章.html
  论文.pdf
  图片与样式等资源/
  .html-reader/
    workspace.json          # 文档身份、路径和打开的标签页
    documents/<文档ID>.json  # 批注、画笔轨迹、笔记、位置、缩放
    backups/<文档ID>/*.html  # 保存源码前的历史版本
```

首次打开旧文档时，应用会合并父子工作空间中已有的批注；迁移保留原记录及索引备份，后续修改和删除不会重复导入旧批注。

批注不会直接插入原 HTML 或 PDF。备份或搬走整个项目文件夹时，请一起保留各层隐藏的 `.html-reader` 目录。应用内重命名或移动文件会保留文档 ID；外部重命名可在原路径已消失且文件内容未变时恢复关联。

删除通过系统废纸篓（Windows 为回收站）完成，关联的批注仍保留。恢复原文件后可以继续读取笔记。移动 HTML 时，相对图片、CSS、脚本链接仍按新目录解释；应用不会自动重写这些源文件链接。

应用的最近工作空间设置保存在系统的应用数据目录中（macOS 为 `~/Library/Application Support/页间`，Windows 为 `%APPDATA%\页间`）。应用本身不上传文档；HTML 里原本引用的远程字体、脚本、图片仍会从对应网站加载。随包演示文档完全离线可用；用户自己的 HTML 若依赖 MathJax 等远程脚本，仍需网络。

## 开发与验证

需要 Node.js 22.13+，推荐使用 Node.js 22。项目包含 `.nvmrc`。

```sh
npm ci
npm run dev        # Vite + Electron 桌面开发
npm run build      # 类型检查、前端与阅读脚本构建
npm start          # 运行已经构建的桌面应用
npm test           # 文件保存、备份、冲突、路径边界等测试
npm run test:e2e   # 真实 Electron 中的交互回归测试
npm run test:pdf  # 单独验证 PDF 阅读、批注、双栏、密码与重启恢复
npm run test:zoom # 单独验证 Command + 滚轮缩放、阅读位置与保存
npm run test:reading # 单独验证拖拽双栏、分栏关闭、Tab 和全选退出
npm run test:annotations # 单独验证便签、局部擦除、中文提示和侧栏状态
npm run pack       # 构建当前架构的 .app
npm run dist:mac   # 构建 Apple 芯片 arm64 的 DMG 和校验文件
npm run dist:win   # 在 Mac 上交叉构建 Windows x64 安装程序和校验文件
```

`npm run dev:web` 提供只用于开发检查的网页入口。系统文件夹选择、访达 / 资源管理器、废纸篓 / 回收站等功能需要桌面版本。不要同时用多个开发实例编辑同一个工作空间。

自动测试使用仓库中的 `samples/` 原创演示文档和测试代码生成的临时文件，不依赖个人资料或外部账号。覆盖本地资源、沙箱隔离、高亮、页面便签、手绘、局部擦除、撤销、笔记、目录、源码保存与备份、重定位、改名、移动、冲突和重启恢复。截图保存在系统临时目录。

开发时可以用 `FOLIO_WORKSPACE=/你的/HTML目录 npm run dev` 指定本地文件夹。额外的本地兼容性测试可设置 `FOLIO_TEST_SAMPLES`，默认不需要。个人阅读材料、批注、备份和本地配置均不进入版本控制或安装包。

## 实现结构

- `electron/workspace.cjs`：文件夹边界检查、文档身份、串行原子写入、备份和冲突检测。
- `electron/main.cjs`：窗口、原生菜单、文件选择、IPC 和文档资源协议。
- `src/pdf/pdf.ts`：PDF.js 页面渲染、文字层、页码、书签与密码处理。
- `src/reader/runtime.ts`：文档内的文字定位、SVG 手绘层与阅读事件。
- `src/hooks/useDocuments.ts`：标签页、草稿、批注历史和持久化队列。
- `src/components/`：文件树、工具栏、阅读区、源码编辑器、批注笔记栏。

文档在独立沙箱 iframe 中运行，无法直接访问文件系统接口。文件操作只允许在当前项目范围内进行。源码编辑器按需加载，阅读界面无需先加载编辑器。

本版本支持 PDF 阅读与批注，并优先支持本地 UTF-8 静态 HTML、常见网页脚本、相对资源与公式。复杂网页应用、登录网站、嵌套网页、canvas 内部的文字批注、跨设备同步和 PDF 式分页导出不在当前版本范围内。页面大幅改版后，跨多个段落的自由手绘可能需要重新绘制。
