# 任务：给一篇论文写伴读笔记

伴读笔记是给读者配着论文原文看的：读者读原文之前先看它，知道这篇论文要解决什么、该重点看哪里；读的过程中卡住了，回来查它。它不是摘要的翻译，也不是逐段复述。

读者的背景：{{reader}}

## 1. 确定是哪篇论文

用户现在打开的文档是：`{{document}}`

- 如果它是一篇论文（通常是 PDF），就写它。
- 如果上面是空的，或者它不是论文（比如是一篇已有的伴读笔记、日报、普通网页），用 list_library 找文献库里「在读」的论文；没有在读的，就找最近加入、有 PDF 文件、还没有伴读笔记的那一篇。
- 都找不到，就直接说明“请先打开一篇论文再运行”，然后结束，不要新建文件。

先用 list_files 看 `{{output}}` 文件夹里有没有这篇论文的伴读笔记（文件名通常就是论文的简称或标题）。已经有了，说明情况后结束，不要重写。

## 2. 读完全文

用 read_document 把论文读完，PDF 按页分段读（例如每次 6–8 页），不要只读摘要和结论。附录里只看方法细节和关键的补充实验。边读边记下：

- 论文自己说的贡献是什么，前人的做法卡在哪里；
- 方法的每一步在做什么、为什么这样做（而不是别的做法）；
- 关键的公式、图和表在第几页、想说明什么；
- 实验的设置（数据、对比的基线、指标）和主要数字；
- 作者承认的局限，以及你读下来觉得没有说清楚或值得怀疑的地方。

## 3. 写笔记

照输出模板的结构写一篇 HTML，用 create_html 新建到 `{{output}}/论文简称或标题.html`（文件名不要带冒号、问号、斜杠这些符号）。要求：

- **用中文写**，术语第一次出现时写“中文（English）”，之后用中文。
- **先讲直觉，再讲细节**。每个方法步骤先用一两句大白话说它在干什么，再讲公式。能举一个具体的小例子就举。
- **公式要解释**：每个符号是什么、这一项起什么作用、去掉它会怎样。公式用模板里 `.formula` 的写法（普通文字和上下标，不要 LaTeX 源码）。
- **指路**：重要的图、表、公式写明在原文第几页（“原文第 5 页图 2”），让读者能对着看。
- **数字要准**：实验结果只写论文里读到的数字，不要凭印象补。没读到的就不写。
- **说人话**：不要“本文提出了一种新颖的……”这种套话，不要逐句翻译摘要。
- 「值得追问」里写三到五个真问题：读者读完应该能回答的，或者这篇论文留下没回答的。
- 篇幅以讲清楚为准，一般 2000–4000 字。

## 4. 记进文献库

用 list_library（query 写论文标题里的关键词）看这篇论文在不在文献库里，然后用 update_library：

- 在：带上它的 id，把 summary 设为模板里那句「一句话总结」，files 写上你刚新建的笔记文件；它还是「未读」的话把 status 设为 reading。
- 不在：新增一条，写上从论文首页读到的 title、authors、year，files 写论文文件和笔记文件，summary 同上，status 设为 reading。

不要把论文标为已读：读没读完由读者自己说了算。
