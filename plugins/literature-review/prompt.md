# 任务：根据文献库写一篇文献综述

主题：{{topic}}（空着就综述整个文献库，自己从论文里归纳出一个贴切的题目）
范围：{{scope}}（空着就由主题决定用哪些论文）

这篇综述是读者自己的：材料是他文献库里的论文，以及他读的时候划的重点、写的笔记。它要帮读者把读过的东西连成一张图，看清各篇之间的关系，而不是把摘要一篇篇摆出来。

## 1. 看文献库

用 list_library 看文献库（论文多时用 offset 翻页看完）。按主题和范围挑出相关的论文：

- 范围写了标签、分类或书单，就按它筛（list_library 的 tag、query）。
- 范围写“只用已读的”，就只用已读的论文。
- 相关的论文超过 30 篇时，挑最重要的 30 篇：已读的、有总结或笔记的优先。

文献库是空的，或者一篇相关的都没有，就说明情况后结束，不要新建文件。

## 2. 读材料

对挑出的每一篇，按这个顺序取材料，够用就不必再往下读：

1. list_library 里已有的「总结」；
2. 用 get_paper 看它：读者在它各个文件里划的重点和写的笔记都在里面，是最要紧的材料，综述里要用上，并在「你的笔记」那一栏体现；
3. 它有精读笔记（HTML 或 Markdown 文件）的话，用 read_document 读笔记；
4. 都没有，再用 read_document 读论文的开头几页（摘要、引言、结论），不要通读每一篇。

没读的论文只看标题、年份、出处和摘要性的信息，用来写「接下来读什么」。

## 3. 写综述

照输出模板的结构写一篇 HTML，用 create_html 新建到 `{{output}}/综述-主题-{{today}}.html`（文件名里的主题用几个字概括，不要带冒号、斜杠等符号）。要求：

- **按思路组织，不按论文组织**。先归纳出三到六条主线（问题的几种解法、几个发展阶段、几派观点），每条主线下面讲清楚它的想法、代表论文各自往前推了哪一步、彼此的分歧。
- **比较要落到实处**：谁用了什么假设、换来了什么、付出了什么代价。能列表比较的就列表。
- **引用用编号** [1]、[2]，和文末「参考文献」一一对应；每个论断都要有出处。
- **用上读者的笔记**：读者在某篇里划了什么、写了什么看法，和综述的论点有关就引用，写明“你在 [3] 里划了：……”。
- **只写读到的**：没有读到的实验数字、结论不要写；不确定的地方直说“库里的材料不足以判断”。
- **说人话**，用中文写，术语第一次出现时带英文。不要“近年来，随着……的飞速发展”这类开头。
- 「还没解决的问题」写具体的问题，不写空话。
- 「接下来读什么」从文献库里**没读的**论文里挑三到八篇，说明每篇为什么值得现在读、读它能补上哪块空白；库里没有未读的就省掉这一节。
- 篇幅以讲清楚为准，一般 2500–5000 字。
