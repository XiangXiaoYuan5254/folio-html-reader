白板练习 / 请页老师讲一遍

公式、代码和图，请页老师讲一遍

页老师会在白板上边写边讲：字幕是他说的话，旁边同时写板书、画示意图。下面准备了四份关于“二分查找”的材料，挑一份让他讲。

怎么开讲（需要先在「AI 设置」里连上一个 AI 服务）
  • 讲一段文字：选中它，点浮动工具条上的「白板」。
  • 讲公式、图表或截图：点工具栏的「白板讲解」，拖动框选那一块（需要能看图的模型）。
  • 和文档无关的题目：点左侧栏底部「白板」旁的 +，新建空白白板，直接提问，或贴一道题的图片。
材料一 · 一段话

在一本按拼音排好的字典里找“页”字，没有人会从第一页翻起。我们会先翻到中间，看看要找的字在前面还是后面，然后把另一半书放到一边不管。每看一次，剩下要找的范围就缩小一半。这就是二分查找的想法，它的前提只有一个：数据必须已经排好序。

试试：选中这段话，点「白板」。

材料二 · 一个公式

在 n 个排好序的数里用二分查找，最多需要比较的次数 k 是：

k=⌊log2n⌋+1

比如一百万个数，最多比较 20 次。

试试：点工具栏的「白板讲解」，框选这个公式，问“为什么是以 2 为底的对数？”。

材料三 · 一段代码
def binary_search(nums, target):
    low, high = 0, len(nums) - 1
    while low <= high:
        mid = (low + high) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

试试：选中整段代码，点「白板」。页老师会逐行讲，还会画出 low、mid、high 怎样移动。可以接着问：“循环条件为什么是 low <= high，而不是 low < high？”

材料四 · 一张图

要找 42：mid 指向 21，42 比它大，左边一半（下标 0 到 3）都不用再看。

试试：框选这张图，问“接下来 low、mid、high 分别会移到哪里？”。

讲的时候，你可以

  • 圈出没懂的地方：讲的途中直接用笔在白板上圈出或划出来，页老师会先停下。在下方说哪里不懂，他会指着你标的地方换个说法再讲。
  • 暂停和变速：按 空格 暂停；速度可以切换 1×、1.5×、2×，也可以翻看字幕记录。
  • 换一种讲法：字幕栏右边的「讲解方式」有三种：「静音讲解」只看字幕和板书；「页老师出声」，他边说边画，你打字提问；「语音对话」，像打电话一样直接开口，你一说话他就停下来听，说“继续”他就接着讲。第一次语音对话会请求麦克风权限，戴耳机效果更好。
  • 先收起来：页老师备课要等一会儿时，点白板右上角的「收起白板」，接着看文档；他想好了会提醒你。
  • 以后再看：讲过的白板会自动保存在左侧栏底部的「白板」里，打开可以接着提问，也可以存入这篇文档的笔记。
