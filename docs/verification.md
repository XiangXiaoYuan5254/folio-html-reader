# 验证范围

## 自动测试

- `npm test`：批注与笔记保存、源码备份、外部修改冲突、改名和移动、路径边界、并发写入、历史数据迁移与局部擦除算法。
- `npm run test:e2e`：真实 Electron 中验证随包 HTML、相对 CSS/脚本、沙箱隔离、文字选择、批注、手绘、便签编辑与尺寸、擦除、撤销、目录、源码保存、重启恢复以及窄窗口。
- `npm run test:reading`：验证首次拖入的左右分栏、各栏关闭、文件移动、Tab 切换工具、全选退出和双栏重启恢复。
- `npm run test:zoom`：验证 Command + 原生滚轮连续缩放、指针附近阅读位置、双栏独立缩放、缩放范围与适合宽度、画笔落点，以及退出时保存最后一次缩放；模拟漏接首次加载通知，检查双栏和已保存批注仍能恢复。
- `npm run test:pdf`：PDF 页面与文字层、高亮笔记、手绘及两种擦除、便签和文本注释、缩放定位、旋转页面、无文字页面、混合双栏、密码重试、损坏文件、原始 PDF 字节与批注重启恢复。可用 `FOLIO_TEST_PDF=/本地/文件.pdf` 额外验证个人 PDF，测试只使用临时副本。
- `npm run test:ai`：在本地模拟的 OpenAI 兼容服务上验证 AI 设置（模型列表、测试连接、Key 不以明文保存）、首次发送确认、流式回答与思考过程、原文引用的核对与跳转、存入笔记、AI 划重点（HTML 与 PDF，一次撤销）、划词翻译存为高亮笔记、源码 AI 修改的对比预览与写入、项目 Agent 的确认与跳过、对话保存。不需要真实 API Key，也不联网。`npm test` 另外覆盖三种接入方式（OpenAI 兼容、Claude、通过模拟的 Codex App Server 使用 ChatGPT 账号）的流式解析与工具调用、各服务的联网搜索、错误说明与重试、原文引用的模糊定位、查找/替换修改和长文档分段。
- `npm run test:ai-live`：用 AI 设置里已配置的真实服务跑一遍问答、划重点、总结、翻译、源码修改、项目 Agent 和 PDF（需要联网，会产生少量费用）；`FOLIO_AI_LIVE=codex` 改为通过本机 Codex 使用 ChatGPT 账号。不在 CI 中运行。
- `npm run test:plugins`：在本地模拟的 AI 服务上验证插件：AI 前沿日报按时间自动运行（不弹任何确认）、从「整个项目」的按钮运行并打开结果；插件只能访问清单里的网站、只能写进自己的文件夹、只能用清单里的工具；第三方脚本插件的工具可用，且在沙箱里不能自己联网、访问页间界面或本地存储；设置 › 插件里的开关、设置保存、第三方插件的提醒和链接检查。`npm test` 另外覆盖插件清单校验、GitHub / Gitee 链接解析、按 commit 安装与更新时新增权限的识别、联网白名单（含跳转）、定时规则和写入范围。
- `npm run test:settings`：统一设置的分类导航，原有助手、白板与菜单仍打开独立 AI 设置，原有主题入口与没有会员入口，服务草稿跨分类保留，键盘焦点与关闭返回，主题和白板声音共用状态，默认出声与已选静音保留，公告独立分类及新旧入口未读红点同步（包括离开公告页后才返回的请求），阅读偏好、读者画像与公告已读状态重启恢复，以及窄窗口布局。使用临时项目与本地公告、会员服务，不使用真实账号或 API Key。
- `npm run test:model-picks`：勾选模型后，已打开过的模型菜单同步更新，保留当前使用的模型。
- `npm run test:companion-prompt`：自定义精读提示词参与生成，保留 HTML 格式、目录与页码链接要求。
- `npm run test:storage`：按类别统计项目数据，确认后清理旧白板、语音、无用数据及旧备份；单元测试另外验证每篇文档最新备份和外部改名文档的数据保留。
- `npm run test:new-file`：新建时建议未占用的文件名，遇到同名文件自动编号并告知实际名称。
- `npm run test:ui-type`：界面字体与缩放即时生效并在重启后保留，正文显示大小不变，可恢复默认值。
- `npm run dist:mac`：类型检查、生产构建、macOS arm64 安装包和 SHA-256 校验文件。

测试数据均在临时工作空间中运行。`FOLIO_TEST_SAMPLES` 可指定额外本地 HTML，`FOLIO_QA_DIR` 可指定截图目录。默认示例不加载远程服务。

## 已知范围

支持本地 UTF-8 HTML 和 PDF 阅读批注。PDF 新增批注保存在项目中，不写入原始 PDF；无文字层的扫描件不提供 OCR，PDF 正文不可编辑。HTML 编辑提供源码和实时预览；没有通用的所见即所得排版编辑、跨设备同步或 PDF 分页导出。页面大幅重排后，跨段落手绘可能需要重新定位。备份阅读项目时需保留 `.html-reader`。
