# 验证范围

## 自动测试

- `npm test`：批注与笔记保存、源码备份、外部修改冲突、改名和移动、路径边界、并发写入、历史数据迁移与局部擦除算法。
- `npm run test:e2e`：真实 Electron 中验证随包 HTML、相对 CSS/脚本、沙箱隔离、文字选择、批注、手绘、便签编辑与尺寸、擦除、撤销、目录、源码保存、重启恢复以及窄窗口。
- `npm run test:reading`：验证首次拖入的左右分栏、各栏关闭、文件移动、Tab 切换工具、全选退出和双栏重启恢复。
- `npm run test:zoom`：验证 Command + 原生滚轮连续缩放、指针附近阅读位置、双栏独立缩放、缩放范围与适合宽度、画笔落点，以及退出时保存最后一次缩放；模拟漏接首次加载通知，检查双栏和已保存批注仍能恢复。
- `npm run test:pdf`：PDF 页面与文字层、高亮笔记、手绘及两种擦除、便签和文本注释、缩放定位、旋转页面、无文字页面、混合双栏、密码重试、损坏文件、原始 PDF 字节与批注重启恢复。可用 `FOLIO_TEST_PDF=/本地/文件.pdf` 额外验证个人 PDF，测试只使用临时副本。
- `npm run dist:mac`：类型检查、生产构建、macOS arm64 安装包和 SHA-256 校验文件。

测试数据均在临时工作空间中运行。`FOLIO_TEST_SAMPLES` 可指定额外本地 HTML，`FOLIO_QA_DIR` 可指定截图目录。默认示例不加载远程服务。

## 发布验证

检查 DMG 完整性、挂载后的应用与 Applications 快捷方式、应用签名完整性、可执行文件架构、全新用户目录首次启动及示例文档。Apple Silicon 版本在本地真实 Mac 验证，当前不发布 Intel 版本。

当前版本使用本地签名，没有 Developer ID 和 Apple 公证。开发机的 Gatekeeper 状态不能证明普通下载用户不会遇到安全提示；首次打开按安装说明处理。

## 已知范围

支持本地 UTF-8 HTML 和 PDF 阅读批注。PDF 新增批注保存在项目中，不写入原始 PDF；无文字层的扫描件不提供 OCR，PDF 正文不可编辑。HTML 编辑提供源码和实时预览；没有通用的所见即所得排版编辑、跨设备同步或 PDF 分页导出。页面大幅重排后，跨段落手绘可能需要重新定位。备份阅读项目时需保留 `.html-reader`。
