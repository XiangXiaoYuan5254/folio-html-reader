## 本次更新

- **白板可以先收起来**：页老师备课要等一会儿时，点白板右上角的「收起白板」，可以接着看文档。标题栏会显示页老师在做什么、已经想了多少秒；想好了会变成「页老师想好了，点开开始讲」。收起期间页老师不会自己讲下去；讲到一半收起的，点开从停下的地方接着讲。
- **工具栏可以放到文字上方**：选中文字后，点工具栏上的箭头，工具栏就移到所选文字的上方（再点一下回到下方）。以后选中文字时都出现在这一侧；这一侧放不下时会自动换到另一侧。
- **白板中途换声音**：讲到一半换了声音，接下来的句子都用新声音说，不会再冒出几句旧声音。换成 ChatGPT 的声音时，会接着上一个声音讲到的地方往下讲，不会从头再来；从 ChatGPT 的声音换走时，它会立刻停下。
- **修复**：关上历史版本面板后马上再打开，列表里少了刚才恢复前自动备份的那一份，选中的也还是上一次的版本。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.19.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.19.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

单元测试全部通过。「收起白板」和工具栏换边在打包前的应用里用本地模拟的 AI 服务检查过；换声音的改动没有接真实语音服务测试，其他功能的 e2e 测试这次没有运行。安装包为 arm64 macOS 与 x64 Windows 版本。
