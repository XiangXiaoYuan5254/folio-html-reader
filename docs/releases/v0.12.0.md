## 本次更新

- **找论文**：在助手的“整个项目”里说“找一篇某领域的论文，下载到某个文件夹”，AI 会帮你找到并存好。
  - 在 OpenAlex（各学科的论文库）和 arXiv（预印本）中查找，看标题、作者、出处、被引次数和摘要挑出合适的论文，可以只要某一年以后的。
  - 把公开的 PDF 下载到你指定的文件夹，文件夹不存在会自动新建。下载前会显示论文标题和链接，点“应用”才下载；已有同名文件时不会覆盖。
  - DeepSeek、通义、Kimi 等任何支持工具调用的模型都能用，不需要另外申请 Key；查找时只把关键词发给 OpenAlex 和 arXiv。
  - 有些出版社的链接需要登录或会拦截下载，这时 AI 会换这篇论文的其他链接，或者换一篇。
- 在“本文”里让 AI 下载论文或新建文件时，它会提醒你切换到“整个项目”。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.12.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.12.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。语音对话目前只有 macOS 版可用。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
