## 本次更新

- **界面主题**：点标题栏右侧的调色板图标（macOS 也可以用菜单“显示 → 界面主题…”）切换，共十套。
  - 只换配色的六套：**青岚**（默认，白底青绿）、**宣纸**（暖白纸色配朱砂红，标题用宋体）、**晴空**（冷调天蓝）、**桃夭**（柔和樱粉），以及深色的 **夜读**（深蓝灰）和 **墨金**（墨色底配鎏金）。
  - 连形状和字体一起换的四套：**新粗野**（粗黑描边、硬投影、撞色）、**报刊**（新闻纸底色、宋体、双线报头）、**终端**（黑底荧光绿等宽字、扫描线）、**极光**（极光渐变背景上的半透明玻璃面板）。
- **跟随系统**：打开后白天和夜间各选一套，随系统的浅色 / 深色外观自动切换。
- 主题只改变应用界面、源码编辑器配色和 PDF 页面之间的底色，HTML 与 PDF 正文保持原样。选择在重启后保留，启动时窗口直接显示所选主题的颜色，不会先闪一下默认配色；Windows 标题栏右侧的按钮也跟着变色。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.10.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.10.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 51 项单元测试和全部端到端测试通过。另在打包前逐一切换十套主题：每套都正确应用、没有界面报错，PDF 页面之间的底色随主题变化，跟随系统开关可用，重启后保留所选主题。安装包为 arm64 macOS 与 x64 Windows 版本。
