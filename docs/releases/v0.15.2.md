## 本次更新

- **复制 AI 的回答**：AI 助手的回答、你的提问和思考过程都可以选中复制了；回答里的代码块有自己的「复制」按钮，只复制代码。之前回答下方的「复制」按钮看起来能用、其实没有复制成功，这次修好了。
- **白板上的长代码**：太长的代码行会在白板宽度内自动换行，接着的部分稍微缩进，原来的缩进保留，不再被右边截断。鼠标移到代码上，旁边会出现「复制」按钮，复制的代码不带行号；点它不会打断页老师。
- **MiniMax 语音不再中途失声**：MiniMax 每个账号每分钟只能生成 10 句（充值后 20 句），以前一节课超过这个数就会讲到一半没声音。现在只提前准备接下来几句，按每分钟的限额排队；某句还没生成好时，白板会等它，并提示声音马上就来。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.15.2-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.15.2-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 57 项单元测试中 56 项通过、1 项只在 Windows 上运行。另在打包前的应用里，用模拟的 AI 接口检查了：AI 回答可以选中，回答里代码块的「复制」只复制代码；白板上的长代码行在框内换行，鼠标移上去出现「复制」，复制的代码不带行号。MiniMax 每分钟限额的改动需要真实的 MiniMax 账号，未单独检查。安装包为 arm64 macOS 与 x64 Windows 版本。
