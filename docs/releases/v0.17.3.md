## 本次更新

- **存入笔记带上你的问题**：AI 助手的回答存入笔记时，你的问题做这一段的标题，不再只写「AI 回答」。问题超过 30 字或有好几行时，标题只放开头，完整的问题放在标题下的引用里。划词提问会带上选中的原文，提问时附的图片（粘贴、拖入或框选的）也一起存进笔记。问题和回答之间有一行加粗的「AI 回答：」分开。总结全文、划重点等快捷操作照旧用它们的名字做标题。
- **「查看笔记」定位到这条回答**：点回答下面的「已存入 · 查看笔记」，笔记会滚到这条回答所在的那一段，标题停在面板顶部；不管它是什么时候存的、后面又写了多少。以前笔记一长，这里会停在笔记最上面。白板「存入笔记」后会定位到那块白板的那一段，「整个项目」里 AI 写了笔记后的「查看笔记」会定位到它写的部分。找不到对应内容（比如已经删掉）时停在笔记最上面。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.17.3-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.17.3-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。（2026-10-08 换成了公证版安装包，应用内容和最初发布的 0.17.3 相同。）

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 73 项单元测试中 72 项通过、1 项只在 Windows 上运行，其中新增的覆盖存入笔记的格式和「查看笔记」的定位。`npm run test:ai` 的 13 项全部通过，其中检查了：笔记前后都写了很多内容时，「查看笔记」停在那条回答的标题；带两张图的提问存入后，笔记里有问题标题和两张图。安装包为 arm64 macOS 与 x64 Windows 版本。
