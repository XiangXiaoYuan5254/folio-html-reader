## 本次更新

- **数位板画画**：用数位板或触控笔画画时，如果笔拖出了阅读区（比如拖到旁边的 AI 助手上）再回来，激光笔的光标会消失，画笔也画不出东西，要点一下别处才恢复。现在拖出去的那一笔停在阅读区边缘，回到阅读区光标照常显示，可以直接接着画。鼠标、触控板和触屏手指的用法不变。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.23.2-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.23.2-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

单元测试全部通过。在应用里用模拟的输入事件检查过：数位笔拖到 AI 助手上抬笔，那一笔当场结束；笔回到阅读区，光标跟着走，可以接着画；鼠标、触控板和触屏手指的正常画线和橡皮擦不受影响。e2e 测试这次没有运行。安装包为 arm64 macOS 与 x64 Windows 版本。
