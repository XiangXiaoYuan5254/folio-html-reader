## 本次更新

- **AI 助手联网搜索**：在助手里提问（“本文”和“整个项目”）时，Claude、DeepSeek、通义千问、Kimi、智谱 GLM、小米 MiMo、OpenRouter 和 Codex 可以联网。要不要搜由模型判断：问到最新的消息、版本、价格，或要核实没把握的事实时才搜，用了搜索结果会注明来源。搜索的内容显示在回答的步骤里（通义千问的接口不告诉页间搜了什么，只看得到回答）。DeepSeek 只有它的 Anthropic 兼容接口能搜，页间提问时自动改走那里，Key 不用换。搜索用的是各家自己的服务，填好的 Key 就能用，按次另外计费。解释、翻译、白板等功能不联网。
- **Mac 上的毛玻璃窗口**：经典六套主题的标题栏和文件树换成系统的侧栏毛玻璃材质，透出模糊的桌面；阅读区和右侧栏保持不透明。新粗野、报刊、终端、极光四套主题保留各自的实色。界面文字以 12–13px 为主，与 macOS 自带应用一致。
- **界面动效**：侧栏整块滑入滑出，阅读区随之变宽；弹窗、菜单、提示从触发处浮现，关闭时短暂淡出；阅读 / 源码切换和批注栏标签的滑块在选项间滑动；文件夹展开收起有高度过渡；换主题时整窗交叉淡入；目录和批注跳转平滑滚动到位置。系统开启“减少动态效果”时全部变为即时。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.17.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.17.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
