## 本次更新

- 在 AI 设置中添加「Google 账号」，点击「用 Google 账号登录」。首次登录会下载 Google 官方 Antigravity 组件，再打开浏览器授权。
- 登录后可在 AI 助手中选择账号可用的模型，使用 Antigravity 额度。插件继续使用单独配置的 API 服务。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.32.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.32.0-win-x64-setup.exe` |

下载后可用 `SHA256SUMS.txt` 校验文件完整性。

**macOS** 安装包使用 Apple Developer ID 签名，并通过 Apple 公证。打开 DMG，把页间拖入 Applications。

**Windows** 安装包尚未进行代码签名。如果 SmartScreen 提示“Windows 已保护你的电脑”，校验文件后选择“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内。
