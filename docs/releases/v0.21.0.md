## 本次更新

- **会员窗口重新设计**：还没开通会员时，左边是深绿烫金的「页间会员」，列出免费版和会员各能用哪些功能；右边选会员时长，三个时长竖着排，价格下面写着填邀请码能减多少，付款按钮写「立即开通 · 价格」。已经是会员的，会员信息显示成同样风格的会员卡。
- **邀请码规则调整**：好友第一次开通会员时填你的邀请码，年度会员减 ¥10，永久会员减 ¥20；月度会员不能用邀请码。每个邀请码只能用一次，用过后会员窗口里会显示“已经被好友用过了”。邀请人不再获得会员天数，也不再有“累计 5 位好友送永久”。
- 永久会员的早鸟价 ¥198 到 11 月 14 日为止。
- 0.20 版的页间看不到邀请好友，更新到这一版后就有了。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.21.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.21.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
