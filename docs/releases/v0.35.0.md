## 本次更新

- 插件可以读 PDF 了：只发了 PDF 的技术报告和论文，插件也能读全文。
- 插件读网页被网站的人机验证挡住时，运行日志会说明原因，不再只显示「返回了 403」。
- 官方插件「AI 前沿日报」1.5.0：每期多一篇深度解读，挑最近最有分量的技术报告或论文，读完全文写成单独的笔记。在「设置 › 插件」里更新。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.35.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.35.0-win-x64-setup.exe` |

下载后可用 `SHA256SUMS.txt` 校验文件完整性。

**macOS** 安装包使用 Apple Developer ID 签名，并通过 Apple 公证。打开 DMG，把页间拖入 Applications。

**Windows** 安装包尚未进行代码签名。如果 SmartScreen 提示“Windows 已保护你的电脑”，校验文件后选择“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内。
