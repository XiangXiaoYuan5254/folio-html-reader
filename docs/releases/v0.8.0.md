## 本次更新

- **自动更新**：页间会在后台检查并下载新版本，下载好后在右下角提示“已准备好”，并列出这次更新了什么。点“立即重启”马上用上新版本；选“稍后”，下次退出页间时自动安装。未保存的源码修改会先像关闭窗口时一样处理，批注和笔记不受影响。
- **手动检查更新**：点标题栏中间的“页间”即可检查；macOS 的“页间”菜单里也有“检查更新…”。
- macOS 上，页间需要放在“应用程序”文件夹里才能自动更新。直接从 DMG 或“下载”文件夹打开时，提示会改为去官网下载。

**这是最后一次需要手动更新。** 0.7.0 及更早的版本还没有自动更新，请按下面的方法装上 0.8.0，之后的新版本都会自动安装。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.8.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.8.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

从旧版更新时请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

自动更新有专门的端到端测试：打包 0.0.1 和 0.0.2 两个版本，由本地服务器提供 0.0.2 的更新文件，让装好的 0.0.1 自己更新。测试覆盖：选“稍后”后退出时静默安装且不重新打开；“立即重启”后安装并重新打开；装好的新版手动检查时提示已是最新版本；macOS 上页间所在文件夹不可写时只提示去官网下载。macOS 版在本机通过这项测试，并在“应用程序”文件夹中验证了替换；Windows 版的同一测试在 GitHub Actions 的 Windows 虚拟机上运行，连同安装、打开方式、端到端测试和卸载检查。

macOS 版另通过构建、单元测试、DMG 与签名校验，以及主流程和打开文件的端到端测试。安装包为 arm64 macOS 与 x64 Windows 版本。
