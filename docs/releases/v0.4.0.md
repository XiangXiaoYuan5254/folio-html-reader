## 页间 · Folio 0.4.0

面向 macOS 的本地 HTML 阅读、批注与项目管理应用。无需账号、Node.js 或服务器，打开文件夹就能开始阅读。

### 下载哪一个？

| 你的 Mac | 推荐安装包 |
| --- | --- |
| Apple 芯片（M 系列） | `Folio-0.4.0-mac-arm64.dmg` |
| Intel 处理器 | `Folio-0.4.0-mac-x64.dmg` |

系统要求：**macOS 12 及以上**。打开 DMG，把“页间”拖到 Applications（应用程序），复制完成后推出磁盘映像，再从应用程序中打开。ZIP 是备用分发格式。

### 首次打开

当前是 **ad-hoc 本地签名版本，尚无 Apple Developer ID 签名和 Apple 公证**。如果 macOS 提示无法验证开发者，尝试打开后，到“系统设置 → 隐私与安全性 → 仍要打开”允许本应用。请确认下载来源为此仓库。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

如提示文件损坏或包含恶意内容，请停止安装并重新下载、核对 `SHA256SUMS.txt`。发布包不要求关闭系统安全保护。

### 主要功能

- 像 IDE 一样管理 HTML 文件夹，递归浏览、搜索、多标签、改名和移动。
- 高亮、下划线以及附着原文的笔记；有笔记时显示三点，悬停即可查看。
- 页面便签、透明文本注释、平滑画笔、箭头、矩形和连续局部擦除。
- 准星画笔光标，按住 E 临时擦除，激光笔轨迹约三秒后消失。
- 笔触面板在点击外部或开始画画时自动收起，第一笔直接生效。
- 目录宽度可拖动并记忆，左右面板可手动收起，批注不会自动打开侧栏。
- HTML 源码编辑与实时预览，保存前备份，检测外部修改冲突。
- 笔记、批注和阅读位置自动保存，提供 Markdown 导出。

### 安装版整理

- 新增 Apple Silicon 和 Intel 两套 DMG / ZIP 安装包。
- 提供中文安装说明及 SHA-256 校验文件。
- 随包提供三篇离线原创演示文章，不包含个人阅读资料或批注。
- 整理了可独立克隆、构建与测试的源码和 MIT 许可证。

### 数据与升级

先退出旧版，再拖入新版并替换。原有阅读项目不在应用包内，更新不会删除它们。批注数据位于项目中的隐藏文件夹 `.html-reader`，备份和迁移时请一起保留。

### 验证与范围

15 项自动测试及真实 Electron 的阅读、批注、源码编辑和恢复测试通过。Apple Silicon 版本在真实 Mac 上验证；Intel 版本另做架构与启动检查，尚未在 Intel 真机上验证。

本版主要支持本地 UTF-8 HTML。暂不包含通用的所见即所得排版编辑、跨设备同步或 PDF 分页导出。用户 HTML 原本引用的远程资源仍需网络。
