## 本次更新

- **用 Kimi 会员**：在 AI 设置里选「Kimi Code」，用 Kimi 会员里的 Kimi Code 额度，不需要 API Key，也不另外付费。
  - Kimi 只允许编程工具使用会员额度，会员的 `sk-kimi-` Key 填在「Kimi」里会被拒绝，所以页间通过这台电脑上的 Kimi Code CLI 连接。先按 [Kimi Code 官网的说明](https://www.kimi.com/code/docs/kimi-code-cli/guides/getting-started.html)安装，再在设置里点「用 Kimi 账号登录」。
  - 页间单独登录，CLI 的登录和会话放在页间自己的数据目录里，和你自己用的 Kimi Code 互不影响。
  - Kimi Code 自带的命令行、读写文件和联网工具都不启用，只让它回答问题或调用页间自己的工具。
  - 模型列表和每个模型的推理强度档位来自你的账号；能看图。
  - AI 设置和模型菜单里显示 5 小时和每周额度的已用比例。回答比直接用 API 慢几秒。
- 原来的「Kimi」改称月之暗面开放平台，按用量付费，用法不变。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.14.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.14.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 57 项单元测试中 56 项通过、1 项只在 Windows 上运行；`npm run test:e2e` 的 10 组界面测试、语音对话和白板论文两组测试通过。另在打包前的应用里检查了 Kimi Code 的三种状态：没装 Kimi Code CLI、装了未登录（用本机真实的 CLI）、已登录（用模拟的 CLI，含额度显示、保存服务和一次流式回答）。安装包为 arm64 macOS 与 x64 Windows 版本。
