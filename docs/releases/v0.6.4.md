## 本次更新

- **便签样式**：已有便签也能调整字体、字号和底色，支持自定义颜色、自动保存和撤销。样式面板默认显示在便签上方，靠近页面边缘时自动调整位置。
- **双栏同步滚动**：开启“同步滚动”后，滚动任意一栏，两篇文档一起移动；关闭后恢复独立滚动。支持 HTML / PDF 混合阅读，不同缩放比例下仍按屏幕距离同步。
- **批注跟随文档**：修复切换父目录、子目录工作空间后批注看似消失的问题。同一文件使用同一份批注，旧记录自动合并并保留迁移备份。
- **访达导入**：从访达复制文件后，点击工作空间中的目标文件夹并按 `⌘V`，也可以右键选择“粘贴文件”，或直接拖入文件和文件夹。同名文件自动保留副本，原文件不移动、不覆盖。

## 下载安装

仅提供 **Apple 芯片（M 系列）版本，支持 macOS 12 及以上**。

推荐下载 `Folio-0.6.4-mac-arm64.dmg`，打开后把页间拖入 Applications。另提供 ZIP、中文安装说明和 `SHA256SUMS.txt`，不需要 Node.js 或单独运行服务器。

更新前退出旧版，再替换应用。批注保存在各篇文档所在文件夹的隐藏 `.html-reader` 中；备份阅读项目时，请保留各层隐藏的 `.html-reader`。阅读资料和批注独立于应用，替换应用不会删除它们。

## 首次打开

本版本采用 ad-hoc 本地签名，**尚无 Apple Developer ID 签名和 Apple 公证**。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”。仅对从本发布页下载并确认来源的应用执行。[Apple 官方说明](https://support.apple.com/zh-cn/102445)

PDF 原文件保持不变，新增批注保存在项目中；当前不提供 OCR、PDF 正文编辑或嵌入新增批注的 PDF 导出。
