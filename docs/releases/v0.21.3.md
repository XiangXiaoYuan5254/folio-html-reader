## 本次更新

- **AI 助手更省心**：同一段对话一次只回答一个问题，多点几下「重试」或任务按钮不会重复发送；点停止后，AI 服务那边也会一起停下，不会在后台继续运行、消耗额度。
- **精读笔记接着写**：写到一半断开时（比如网络中断、服务出错），按钮变成「接着写」，在同一条回答里从断开的地方继续，长文档已经通读过的部分也不用重读。还没开始写就断开时仍是「重试」。
- **对话列表**：历史对话里，正在回答的对话前面有转圈图标；在别的对话里时回答完成的，会标一个小点，点开后消失。
- **等得更久**：模型思考较久时（尤其是不显示思考过程的模型），连续 10 分钟没有任何回应才会停止，之前是 3 分钟。
- **细节改进**：界面和使用上的一些小调整。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.21.3-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.21.3-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

单元测试全部通过。AI 助手的改动在应用里连真实的 Codex 检查过（重复请求、接着写、重试、停止、对话列表的标记），其他功能的 e2e 测试这次没有运行。安装包为 arm64 macOS 与 x64 Windows 版本。
