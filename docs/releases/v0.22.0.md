## 本次更新

- **长文档问得更准**：文档太长、一次放不下时，AI 先读开头，需要别的部分就自己在文档里搜索、翻到对应的地方再回答，查阅的步骤显示在回答上方。最多查 15 轮，查满了就根据已经查到的内容回答。不支持工具的服务，仍然挑和问题最相关的段落一起发过去。
- **AI 记得整段对话**：之前的问答、中途停下或出错的回答都会一起带给 AI，它知道上一条回答停在哪里。聊得久了，较早的部分会自动整理成摘要再接着聊。
- **精读笔记**：手动停下的精读笔记，现在也能点「接着写」；也可以直接在输入框说“继续”，从停下的地方写完。写好之后，可以就笔记里的内容接着问。
- **ChatGPT（Codex）和 Kimi Code 更快**：页间开着时，同一段对话沿用同一个会话，每次只发新的内容，长对话回答更快。中途换模型或思考强度，也在同一个会话里接着用新的设置。
- **用量卡片**：鼠标停在回答下方的模型名上，会弹出这次的用量，输入和输出分开显示，缓存命中显示成百分比；点一下可以固定。
- **新的示例文档**：第一次打开页间时看到的示例文档全部重写，按现在的功能介绍界面、批注和快捷键，并新加了「和 AI 一起读」「白板讲解练习」两篇。
- **细节改进**：界面和使用上的一些小调整。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.22.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.22.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

单元测试全部通过。长文档查阅的 15 轮上限在打包前的应用里用本地模拟的 AI 服务检查过（查满后根据已查到的内容回答；之后还要查的才停下）；Codex 和 Kimi Code 的会话沿用，用模拟的 Codex 与 Kimi Code 检查过，包括查阅途中停下后下一问换新会话。这次的 AI 改动没有接真实的 AI 服务测试，其他功能的 e2e 测试这次没有运行。新的示例文档在应用里以新用户身份打开看过。安装包为 arm64 macOS 与 x64 Windows 版本。
