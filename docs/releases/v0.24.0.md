## 本次更新

- **白板附件**：白板提问时点输入框旁的 **添加附件**，选择或拖入 PDF、TXT、Markdown（`.md` / `.markdown`）、HTML（`.html` / `.htm`）和图片，也可以直接粘贴图片。每次最多 4 份文档和 6 张图片；PDF 单份不超过 20 MB，文本 / Markdown / HTML 不超过 2 MB。附件读取完成后可以查看文件名和读取范围，也可以移除；不写问题直接发送，会讲解附件的主要内容。正文和 PDF 全部页面完整读取，不再按 24,000 字、50 页或扫描图数量截断：放得进所选模型上下文的文档直接发送全文，超长资料逐段读取后综合讲解，显示阅读进度，所有分段处理完成后才回答，失败会提示重试。完整原文随白板记录保存，重新打开或继续追问时仍可读取文档末尾和各页内容（分段笔记是整理结果，不是逐字复述）。PDF 提取全部文字，无文字的页面整页作为图片按批次读取（需要能看图的模型），有文字页面里的图表可另附截图；加密 PDF 需先解锁。HTML 读取静态正文，保留标题、列表、表格和代码，不执行脚本或加载网页资源，网页图片和动态内容可另附截图。
- **全文翻译的图和表**：PDF 的图按图注从原页面裁下来，放在中文图注的位置，图里的文字不用模型照抄。表格照原表的行和列重排成中文表格：模型名、数据集名、指标这类专有名词保留原文，所有数字照抄，原文加粗的数字照旧加粗；表格下面可以展开原表截图核对，实在排不出来的表格用原表截图代替。译文是单个 HTML 文件，发给别人也能直接看。参考文献照抄原文放在文末，正文里的 [12] 点一下就跳到那一条；章节层级按编号统一，开头有可展开的目录；被图表隔断的段落会接回去，两部分接缝处重复的译文会去掉。以前译好、还没有图的译文，再点“全文翻译”选“打开已有译文”，会从原文补上图表。
- **重看讲解**：白板记录里的每块白板都能 **重看讲解**，字幕和板书按原来的节奏再走一遍，进度条可以拖到任意一句，重看不消耗 AI 额度；看完可以「再看一遍」、「接着提问」或结束重看。页老师用语音服务讲的句子也随白板保存，重看时不再向语音服务要一遍；删除白板时一并删除。
- **细节改进**：文档里的图片双击可以放大查看，网络图片由页间代为取回。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.24.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.24.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
