## 本次更新

- **Windows 也能语音对话**：白板的“语音对话”现在 Windows 版也能用，像打电话一样直接开口，页老师讲的时候你一说话他就停下来听。
  - 默认用通义实验室的 SenseVoice 模型在这台电脑上识别，不上传录音。第一次语音对话时下载约 240MB 的模型（先从 ModelScope 下载，不通时换 Hugging Face）。
  - 填了通义百炼或豆包语音的 Key，也可以在语音面板里改成由它们识别，按时长计费。
  - 用电脑自带的声音外放时，页老师的声音可能被当成你在说话，戴耳机更好。
  - 不装 macOS 语音组件也能选 ChatGPT 的声音。
- **更像真人的老师声音**：在 AI 设置的「语音服务」里填通义百炼、豆包语音或 MiniMax 的 API Key，页老师就能用它们的声音讲课，比电脑自带的声音自然得多。每个声音都可以先试听。费用由服务商按字数收取，页间不经手。
- **推理强度跟着模型走**：通义、Kimi、GLM、豆包、OpenAI、Claude、Gemini 按各模型的文档列出它支持的档位和默认档位，Codex 用它模型列表里给出的档位。
  - 去掉了“自动”，每次请求都写明档位。换到一个没有当前档位的模型时，自动换成最接近的档位。
  - 没有单独选档位时：翻译用最低档，解释和白板用最低的“会思考”的档位，聊天用模型的默认档位。
- **余额和用量**：AI 设置和模型菜单里显示 DeepSeek、Kimi、硅基流动、OpenRouter 的账户余额，用完时提醒充值；Codex 显示 ChatGPT 套餐 5 小时和每周的已用比例。
- 通义和豆包的模型列表只列出它们当前的对话模型，豆包只显示账号里已开通的模型。
- 白板讲稿里的“说话：……”念出来时不再带“说话”两个字。
- Windows 上，助手新建文件时会用 Windows 能保存的文件名；用 npm 安装的 Codex（`codex.cmd`）也能找到。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.13.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.13.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。第一次语音对话会请求麦克风权限。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
