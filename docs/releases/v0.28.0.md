## 本次更新

- **更宽敞的阅读界面**：文档标签并入顶部标题栏；主题、阅读提示和设置集中到左下角。Mac 的页间标志在右上角，Windows 的标志在左上角，为系统窗口按钮保留空间。
- **统一的右侧面板**：用“AI 助手与笔记”开关面板，在里面切换批注、笔记、目录和助手，重新打开时保留上次选择。
- **自适应工具栏**：窗口较窄时，放不下的批注工具自动收进“更多工具”，拉宽后恢复显示。白板收起后，阅读工具栏显示讲解进度，可随时回到同一块白板。
- **AI 稳定性与诊断**：改进流式回答中断、输出上限和结束状态的识别与提示，保留已收到的回答。新增本地诊断日志，只记录请求状态、耗时、Token 用量等元数据，不记录对话正文、思考内容或 API Key。
- **公告更新**：应用持续打开时也会定期检查新公告。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.28.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.28.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并通过 Apple 公证。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
