## 本次更新

- **AI 助手**：在“AI 设置”里接入你自己的 AI 服务，按用量向服务商付费，页间不经手。支持 DeepSeek、通义千问、Kimi、智谱 GLM、豆包、硅基流动、Claude、OpenAI、Gemini、OpenRouter 和任何 OpenAI 兼容接口，也支持本机运行的 Ollama、LM Studio。也可以选“ChatGPT（通过 Codex）”，用 ChatGPT 套餐里的 Codex 额度，不需要 API Key。
- **问这篇文档**：点工具栏的 ✦ 或右侧栏“助手”。回答里的小编号是原文引用，点击跳到原文；双栏阅读时同时参考两篇。快捷操作有总结全文、AI 划重点、整理我的批注、出几道思考题；AI 划重点直接在原文加高亮，按一次 `⌘Z` 全部撤销。
- **精读笔记**：为当前论文或文章写一份伴读 HTML，保存在原文旁边并排打开，笔记里的页码可以点回 PDF。
- **划词和看图**：选中文字后可以让 AI 解释、翻译、提问，结果可以存为高亮笔记。可以粘贴、拖入图片，或框选页面上的图表、公式来问。
- **源码 AI 修改**：源码模式下点“AI 修改”，先看改动对比和修改后的预览，确认后才写入。
- **整个项目**：让 AI 阅读、搜索项目里的文档，帮你加高亮、写笔记、修改或新建 HTML。每个修改都先预览，点“应用”才执行。
- **隐私**：API Key 只保存在这台电脑上，只发送给对应的服务商。第一次使用某个服务时会先询问是否同意发送文档内容；可以为某个项目停用 AI。不用 AI 时，页间和以前一样不上传任何内容。
- **右侧栏可以调宽**：拖动右侧栏的左边缘调整宽度，批注栏和助手分别记住各自的宽度，双击恢复默认。
- **文档笔记**：可以在“预览”和“编辑”之间切换，预览时按 Markdown 显示。
- **高亮笔记**：预览可以把鼠标移上去停住、滚动看完长笔记，点击直接编辑；编辑时 A−/A+ 调整笔记字号。
- 文件树的“⋯”菜单点别处或按 `Esc` 就会关闭。

已安装 0.8.0 的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.9.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.9.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 51 项单元测试和全部端到端测试通过，包括新的 `npm run test:ai`：在本地模拟的 AI 服务上验证 AI 设置、问答引用、划重点、划词翻译、看图与框选、源码修改、项目 Agent、精读笔记和对话保存，不需要真实 API Key。安装包为 arm64 macOS 与 x64 Windows 版本。
