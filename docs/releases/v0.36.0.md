## 本次更新

- 可以打开 Word 文档（.docx）、代码、纯文本和 CSV 了：代码按语言高亮、显示行号，CSV 显示成表格，Word 保留标题、列表、表格和图片。和 HTML 一样可以高亮、批注，AI 助手也能读。
- AI 设置新增「修改文件前」：每次询问、自动（只在改动原有内容时询问）或全部直接应用。默认「自动」，加高亮、新建文件、下载论文这类只增加内容的修改直接应用。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.36.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.36.0-win-x64-setup.exe` |

下载后可用 `SHA256SUMS.txt` 校验文件完整性。

**macOS** 安装包使用 Apple Developer ID 签名，并通过 Apple 公证。打开 DMG，把页间拖入 Applications。

**Windows** 安装包尚未进行代码签名。如果 SmartScreen 提示“Windows 已保护你的电脑”，校验文件后选择“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内。
