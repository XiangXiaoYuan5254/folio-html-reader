## 本次更新

- **页老师讲得更细**：每句话都配着板书，推导一步写一行、不跳步；讲算法、迭代、几何变化时，拿一个具体例子在白板上一步步走一遍。问完问题或写完关键式子，会停一下给你想的时间，字幕下方有一条慢慢缩短的细线。字幕节奏也放慢了一些。
- **白板视角跟着笔走**：要写或要指的地方不在视野里时，白板会平稳地移过去，等移到了再落笔；回头指前面写过的内容时，会在那里停留一会儿再回来。
- **思考太久时给出提示**：页老师想了 25 秒还没开口，会提示当前的推理档位，并建议在右上角换成低一档，下次会快一些。
- **AI 修改源码可以附截图**：在「源码 → AI 修改」里粘贴、拖入或选择最多 6 张图片，比如页面现在的截图或想要的样子，和修改要求一起发给 AI。不支持图片的模型会提示，不会发送图片。
- **源码与实时预览之间可以拖动**：和分屏阅读一样的分隔线，宽度会记住，双击恢复等宽。
- **Windows 上的 Codex**：从 Microsoft Store 安装的 Codex 应用也能找到，并优先于旧的 Codex 命令行工具。
- **ChatGPT 语音只用自己的话讲**：Codex 实时语音没法保证逐字照着讲稿念，所以去掉了「照稿念」选项，之前选了它的会自动改为用自己的话讲。
- 白板更能读懂各种模型的输出：分成几行写的公式、漏了 `$` 的公式、没有用代码块包起来的代码，都能正确显示。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.15.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.15.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
