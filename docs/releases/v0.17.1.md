## 本次更新

- **右侧栏宽度各标签共用**：右侧栏只记一个宽度。在助手里拖宽了，切到批注、笔记、目录也一样宽，不再每个标签各记各的。
- **更新提示列出跳过的版本**：以前跳过几版再更新时，右下角的提示卡片只显示最新一版的内容。现在会列出从你装的版本以来每一版的更新内容，按版本分开、最新的在上。这要等装上 0.17.1 之后的下一次更新才看得到；这次从旧版更新到 0.17.1，提示还是只显示本版。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.17.1-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.17.1-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 63 项单元测试中 62 项通过、1 项只在 Windows 上运行。`npm run test:update` 的 5 个场景全部通过，其中检查了：0.0.1 跳过 0.0.2 直接更新到 0.0.3 时，提示卡片按版本列出 0.0.3 和 0.0.2 的更新内容，不列已安装的 0.0.1。右侧栏宽度的改动由作者自测。安装包为 arm64 macOS 与 x64 Windows 版本。
