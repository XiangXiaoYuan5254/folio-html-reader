## 本次更新

- **白板讲解**（原型）：选中文字后点浮动工具条上的“白板”，或点工具栏的白板按钮框选页面上的公式、图表、截图（需要能看图的模型）；和文档无关的题目可以直接打开空白白板提问，也可以粘贴、拖入图片。
  - 页老师边说边写：字幕是它说的话，同时写板书、公式和带行号的代码，一笔一笔地画示意图、数组、链表、树、函数图像和空间曲面，用圈、划线、荧光笔、箭头和旁注指着讲。
  - 讲的途中用笔圈出没懂的地方，页老师会停下，指着你标的地方换个说法重讲。可以暂停（空格）、切换 1× / 1.5× / 2× 速度、查看字幕记录。
  - **讲解方式**有三种：静音讲解；页老师出声（你打字提问）；语音对话（macOS），像打电话一样直接开口，随时打断。可以用这台电脑的中文语音（在本机识别，不上传录音），也可以用 ChatGPT 的声音（通过 Codex，用 Codex 账号的额度）。第一次语音对话会请求麦克风权限。
  - 白板自动保存在项目的 `.html-reader/boards` 中，文件树和“白板记录”里列出本项目的全部白板，打开后可以接着提问。
- **AI 回答显示公式**：助手、划词和文档笔记里的 LaTeX 公式直接排版显示。
- **各功能的模型**：在 AI 设置里为解释、翻译、白板等功能分别选服务、模型和推理强度；选的档位原样使用，不会被自动调低。
- **读者画像**：在 AI 设置里写一段自我介绍，制作精读笔记时会按你的背景和基础来写。
- **文档笔记可以放图片**：粘贴或拖入的截图保存在项目里，点开可以放大查看；白板也可以存进笔记。
- 用 ChatGPT 账号（Codex）提问时，模型可以按需联网搜索，搜索的内容显示在回答的步骤里。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.11.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.11.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。语音对话目前只有 macOS 版可用。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
