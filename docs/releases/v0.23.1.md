## 本次更新

- **触屏上直接画**：在带触摸屏的电脑上（比如 Surface），选中画笔、橡皮擦、箭头、矩形、激光笔、便签或文本注释后，可以直接用手指或触控笔在页面上画，页面不再跟着滚动。画的时候另一根手指或手掌碰到屏幕，不会打断这一笔。切回「选择文字」后，手指拖动照常滚动页面。鼠标和触控板的用法不变。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.23.1-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.23.1-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

单元测试全部通过。触屏画线在应用里用模拟的手指和触控笔检查过：手指和笔都能画、页面不滚动，第二根手指不打断正在画的一笔，鼠标画线和「选择文字」下的手指滚动不变。没有在真实的触屏设备上测试；e2e 测试这次没有运行。安装包为 arm64 macOS 与 x64 Windows 版本。
