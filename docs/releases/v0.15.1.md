## 本次更新

- **窄窗口下的批注工具**：窗口太窄放不下所有批注工具时，放不下的收进工具栏末尾的「更多工具」菜单，不会再被挤出看不见。正在用的工具在菜单里时，按钮显示它的图标。
- **白板图片上的标记**：在白板的图片上圈一小块或划一道线，页老师会知道你标的是图片的哪一部分，而不是当成空白处的笔迹。用触控板或手指滑动白板时，也会打断白板正在进行的自动移动。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.15.1-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.15.1-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 57 项单元测试中 56 项通过、1 项只在 Windows 上运行。另在打包前的应用里检查了窄窗口下的「更多工具」菜单：放不下的工具收进菜单，从菜单里选工具后按钮显示该工具。白板图片标记的改动未单独做端到端检查。安装包为 arm64 macOS 与 x64 Windows 版本。
