## 本次更新

- **换模型更顺**：用 ChatGPT（Codex）时，对话中途换回默认模型，下一次回答就用上默认模型，之前会继续用刚才选的模型。
- **长文档查阅**：AI 在长文档里查阅时，如果写错了文档名，会被告知正在读的是哪几篇，自己改过来接着查，不会去找没有的文件列表。
- **精读笔记**：精读笔记停下后，只要页间没关，仍可以「接着写」或说“继续”；重新打开页间后已经接不上了，AI 会说明需要重新点「制作精读笔记」，不再说能接着写。
- **细节改进**：界面和使用上的一些小调整。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.22.1-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.22.1-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

单元测试全部通过。这次的 AI 改动没有接真实的 AI 服务测试，其他功能的 e2e 测试这次没有运行。安装包为 arm64 macOS 与 x64 Windows 版本。
