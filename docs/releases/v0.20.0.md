## 本次更新

- **邀请好友**：每台电脑都有自己的 6 位邀请码，在会员窗口里能看到（付费会员直接显示，其他人点底部的「邀请好友得会员」），点「复制邀请」就能把邀请码和下载地址发给好友。
  - 好友的电脑首次开通会员时，在付款按钮上方填写邀请码，任何套餐立减 ¥5。付过款的电脑不能再用邀请码，也不能填自己的。
  - 好友开通月度会员，你获得 7 天会员；开通年度或永久会员，你获得 30 天会员。
  - 累计 5 位好友开通年度或永久会员，你获得永久会员，之后这个邀请码停用。
  - 卡片上显示已邀请几位好友，以及开通年度或永久的进度。好友退款时，因这一单得到的奖励一起收回。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.20.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.20.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

单元测试全部通过。邀请码的整个流程（立减、各种不能用的情况、7 天和 30 天奖励、第 5 位送永久、之后停用、退款收回与恢复、结束活动）用脚本对服务器逐项检查过；会员窗口在打包前的应用里连本地激活服务器检查过新用户、填错码、填对码和付费会员几种情况。激活服务器已先部署。其他功能的 e2e 测试这次没有运行。安装包为 arm64 macOS 与 x64 Windows 版本。
