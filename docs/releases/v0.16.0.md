## 本次更新

- **笔记边写边排版**：右侧的笔记改成阅读和书写在同一页，写下的标题、加粗、列表、待办、引用、代码、公式、表格直接显示成排好的样子，不用懂 Markdown。顶部按钮可以设段落样式、加粗、斜体、删除线、列表、编号、待办、引用和字号，**+** 插入代码块、公式、分割线、表格和图片，在空行输入 `/` 也能按名字插入。回车延续列表，空项上再按回车结束；Tab / Shift+Tab 调整层级。底部 A− / A+ 调整笔记字号。从笔记复制出去的是纯文字，在笔记之间复制粘贴保留格式。笔记仍以 Markdown 保存，导出和 AI 存入笔记都不受影响。
- **选中文字的工具栏在选区下方**：松开鼠标的地方就是工具栏出现的地方，下方放不下时才放到上方。AI 解释、翻译等卡片可以拖住标题挪开，看清被挡住的内容；点卡片外面任意地方就收起。
- **AI 改源码可以接着提意见**：在「源码 → AI 修改」里，对 AI 给出的修改不满意，直接说哪里不对，它会在刚才的修改上继续改，并记得这个文件之前几轮说过什么、哪些采用了、哪些没采用。
- **白板上的数值能换掉了**：页老师讲数组交换、指针移动时，会先擦掉旧的数字再写新的，写在同一位置的新字会替换旧字，不再叠在一起。写 `code c1 | python` 这样的代码行也能正确识别语言。
- **复制自己的提问**：AI 助手里你发出的消息也有「复制」按钮。
- **连着发的版本只更新一次**：以前页间下载好一个新版本、还没重启时，即使又发了更新的版本也不会再检查，于是要先装上一版，重开后再更新一次。现在下载好之后仍按时检查，有更新的版本就改下最新的，安装时直接装最新版。从 0.16.0 开始生效。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.16.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.16.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 57 项单元测试中 56 项通过、1 项只在 Windows 上运行。`npm run test:update` 的 5 个场景全部通过，其中新加的一项：0.0.1 已下载好 0.0.2 时服务器换成 0.0.3，再检查会改下 0.0.3，退出后直接装上 0.0.3，且 0.0.2 不会重复下载。笔记编辑器在打包前的应用里检查了：标题即时排版、列表回车延续、工具栏加粗、以 Markdown 保存、复制出去为纯文字。其余改动由作者自测。安装包为 arm64 macOS 与 x64 Windows 版本。
