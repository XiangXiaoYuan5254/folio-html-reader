## 本次更新

- **白板卡住会自动重试**：用 DeepSeek、通义千问、智谱等会一边思考一边把思考过程发回来的服务时，页老师备课的思考如果停了 30 秒还没开始讲，页间会在旁边再问一次。两次请求同时进行，哪个先开始讲（或先结束）就用哪个，另一个停掉，所以原来那次只是慢、不是卡住时也不会白等。每次最多重试一次。
- **看得到备课进度**：页老师备课时，状态栏除了用了多少秒，还显示已经想了多少字。超过 10 秒没有新内容时，下面会说明现在的情况：还在等服务响应、稍后会自动重试，或者已经重试过、请稍后再试。

已安装 0.8.0 或更新版本的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.17.4-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.17.4-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

0.7.0 及更早的版本没有自动更新，请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

`npm test` 的 74 项单元测试中 73 项通过、1 项只在 Windows 上运行，其中新增的一项覆盖：思考停住的请求会被再问一次并采用先开讲的那个；只是慢的那次先开讲时保留它；不发回思考过程的服务不会被重试。另在打包前的应用里用本地模拟服务检查了白板：思考停住后显示已想的字数和「稍后会自动重试」，30 秒后只重试一次，第二次的讲解正常画出，停住的那次被停掉。其他功能的 e2e 测试这次没有运行。安装包为 arm64 macOS 与 x64 Windows 版本。
