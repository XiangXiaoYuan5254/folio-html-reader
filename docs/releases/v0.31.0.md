## 本次更新

- 支持 Markdown：可以像 HTML 一样阅读、高亮和批注，也能点「源码」边改边看预览；点 ＋ 可以新建 Markdown。
- 可以打开图片（PNG、JPG、GIF、WebP 等），用画笔、箭头、便签和文本注释直接标在图上。
- 界面字体列表显示字体的中文名，可以用中文搜索；新装的字体不用重启就能选。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.31.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.31.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并通过 Apple 公证。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
