## 本次更新

- **全文翻译**：助手里的「全文翻译」把当前论文或文章逐段译成中文，存成原文旁边的 `论文名-译文.html`，并排在右栏打开。先译开头一部分，定下标题和术语的译法（术语对照放在译文开头），其余部分照着这张表同时翻译，译好的部分每隔几秒补上一次。参考文献列表不翻译，公式按上下文还原后显示。中途可以停下，点「接着翻」只翻剩下的部分；译过的文档再点“全文翻译”，会先问是打开已有译文还是重新翻译；很长的文档会先说大概要用多少 token。
- **译文和原文对照**：鼠标移到译文段落上，左边会出现页码，点它 PDF 会跳到原文这一段并短暂标出。译文和它的 PDF 并排、打开 **同步滚动** 时，两边按段落对齐着一起滚，不再按相同的距离滚。
- **并排时的对话单独保存**：两篇文档并排时，AI 助手里的对话属于这两篇；只打开其中一篇时，历史对话里的「和其他文档并排时的对话」也会列出它，点一下就把另一篇并排打开，接着聊。并排时选中文字提问，AI 知道这段出自哪一篇。
- **交换左右两栏**：双栏阅读时，点中间分隔线顶端的 **⇄**，或把一栏的标题拖到另一侧，两篇文档带着过渡动画左右互换，各自的阅读位置和栏宽不变。
- **细节改进**：界面和使用上的一些小调整。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.23.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.23.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
