## 本次更新

- **Windows 版**：新增 Windows 10 / 11（64 位）版本。中文安装向导，默认只为当前用户安装，不需要管理员权限。安装后在资源管理器中右键 HTML 文件，选择“打开方式 → 页间”即可阅读，不会更改默认浏览器。窗口使用 Windows 原生的最小化、最大化和关闭按钮，快捷键使用 `Ctrl`，支持 `Ctrl` 加滚轮缩放、`Ctrl+Y` 重做，也可以直接粘贴在资源管理器中复制的文件和文件夹。
- **源码历史版本**：修改源码前，页间会自动备份原来的版本（每篇文档每 10 分钟最多一份）。在源码模式点“历史版本”可以预览任意一版并一键恢复；恢复时会先备份当前内容，恢复错了也能找回。较早的备份按时间自动清理。
- **直接打开文件**：在访达中双击 HTML、使用“打开方式”，或把 HTML / PDF 拖到程序坞图标上，页间会直接打开它。文件在当前项目或最近用过的项目里时，就在那个项目中打开；否则打开它所在的文件夹。Windows 上同样支持。
- **阅读区**：鼠标停在正文上时，不再冒出“HTML 阅读区”的提示。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.7.0-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.7.0-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。本版本采用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和 Apple 公证。若系统提示无法验证开发者，请先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

更新前请先退出旧版：Mac 替换应用，Windows 直接运行新版安装程序。批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。

## 验证

Windows 版在 GitHub Actions 的 Windows 虚拟机上完成构建和静默安装，并对安装后的应用做了端到端测试：首次启动、标题栏按钮、批注保存、`Ctrl` 加滚轮缩放、应用运行中和未运行时从资源管理器打开文件、粘贴资源管理器复制的文件、专注阅读全屏；卸载后确认程序和注册表项清理干净。源码编辑与历史版本、标签页、打开文件的端到端测试也在 Windows 上通过。

macOS 版通过构建、单元测试、DMG 与签名校验、安装包首次启动检查，以及打开文件和缩放的端到端测试。安装包为 arm64 macOS 与 x64 Windows 版本。
