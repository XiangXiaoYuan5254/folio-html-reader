## 本次更新

- **邀请语改为第一人称**：会员窗口「邀请好友」里点「复制邀请」，复制出来的话改成“我在用「页间」读文档，首次开通会员时填我的邀请码 ……，可立减 ¥5。下载：……”，直接发给好友更自然。邀请规则不变。
- 去掉了录制演示视频时用的一个开发开关，对正常使用没有影响。

已安装的页间会自动收到这次更新。

## 下载安装

| 系统 | 下载文件 |
| --- | --- |
| macOS 12 及以上，Apple 芯片（M 系列） | `Folio-0.20.1-mac-arm64.dmg` |
| Windows 10 / 11，64 位 | `Folio-0.20.1-win-x64-setup.exe` |

另提供 `SHA256SUMS.txt` 用于校验下载完整性。

**macOS**：打开 DMG，把页间拖入 Applications。安装包使用 Apple Developer ID 签名，并已通过 Apple 公证，可以直接打开。

**Windows**：运行安装程序，按向导完成安装。安装程序尚未进行代码签名，若 Windows SmartScreen 提示“Windows 已保护你的电脑”，请点击“更多信息 → 仍要运行”。

批注和阅读数据保存在项目文件夹中的 `.html-reader` 目录内，更新不会影响。
