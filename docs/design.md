# 界面与交互约定

三栏桌面阅读器：文件树、HTML 阅读区、可手动开关的批注栏。左侧宽度可拖动并记忆；正文按原网页的响应式规则铺满阅读区域。窄窗口下侧栏作为抽屉出现。

界面使用系统字体与线性图标，配色来自 `src/themes.css` 中的主题变量：默认青岚为青绿强调色，另有宣纸、晴空、桃夭三套浅色和夜读、墨金两套深色主题；新粗野、报刊、终端、极光四套在 `src/theme-styles.css` 里还改变描边、圆角、阴影和字体。主题可跟随系统外观切换。样式表只引用变量，新增颜色先加变量再在每套主题中取值。中文悬停提示说明每个工具的用途。页面的字体、颜色、SVG 与布局由原 HTML 决定，主题不改变正文。

高亮后继续阅读；点击已有高亮才显示编辑操作。有笔记的高亮用三点区分，悬停查看笔记。便签和文本注释在页面内编辑，批注不会主动展开右侧栏。

画笔使用中心定位的准星光标。橡皮擦以实际擦头范围连续擦除局部笔迹，手势可以整体撤销。激光笔是短暂指示，不进入持久化数据。

笔触设置在内部调整时保持打开，点击外部时收起。HTML 阅读区通过已有的消息通道通知应用交互开始，首个绘图手势正常执行。

动效统一取自 `src/styles.css` 顶部的时长与缓动变量：出现快、落定柔，离开比出现更快；系统开启“减少动态效果”时全部变为即时。侧栏整块滑入滑出、阅读区随之变宽。弹窗、菜单、提示从触发处浮现，关闭时短暂淡出（`src/motion.ts` 的 `Exit`），离开中的浮层不可点击。分段切换的滑块与批注栏标签下划线在选项间滑动；文件夹展开收起有高度过渡；换主题时整窗交叉淡入。目录和批注跳转平滑滚动到位置。

在 Mac 上，窗口本身是系统的毛玻璃侧栏材质：经典六套主题的标题栏和文件树只铺一层半透明主题色，透出模糊的桌面；阅读区和右侧栏保持不透明。新粗野、报刊、终端、极光四套保留各自的实色。界面文字以 12–13px 为主，与 macOS 原生应用一致。
